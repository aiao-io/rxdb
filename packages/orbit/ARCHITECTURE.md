# Orbit 架构与边界

Orbit 是独立维护的 Web 应用运行内核。本文记录当前实现、刻意不支持的行为与安全边界；不代表性能对比或恶意代码隔离承诺。

设计参考基线为腾讯开源项目的提交 `c45932998c0602f34454df8d3e29f4d33a38446a`（2026-11-07）。第三方版权声明与许可原文见 [THIRD-PARTY-LICENSE.txt](THIRD-PARTY-LICENSE.txt)。

## 运行模型

| 能力     | 实现                                              | 约束                                                          |
| -------- | ------------------------------------------------- | ------------------------------------------------------------- |
| 应用文档 | 每个实例使用独立的原生 iframe                     | 浏览器负责相对路径、模块、动态导入、CSP、资源请求与 HTTP 缓存 |
| 窗口视口 | Web Component 与 ShadowRoot 承载可见 iframe       | 应用浮层不逃逸到宿主或其他窗口                                |
| 实例身份 | appId、instanceId、version 与显式 ready 生命周期  | 同一运行时内 instanceId 不可重复；失败实例需重新创建          |
| 消息通信 | 来源验证握手后建立每实例 MessagePort              | 端口绑定后不再消费全局消息广播                                |
| 生命周期 | hide/show 保留 iframe；dispose 同步释放端口与监听 | 隐藏不等于暂停；销毁后实例不可复用                            |
| 路由     | 同一文档内的 SPA history/hash 导航保留连接        | 完整文档导航会断开连接，宿主应创建新实例                      |
| 资源缓存 | 使用浏览器 HTTP 缓存                              | 不提供自定义预加载、离线缓存或缓存淘汰                        |

## 安全边界

本包只接纳运营者批准的协作应用。同源 iframe 与 `allow-same-origin` 不能阻止恶意应用访问 parent 或同源存储；sandbox 不是产品权限系统，原生 localStorage/IndexedDB 不按 instanceId 自动分区，也不保证 CPU 死循环、浏览器崩溃或失去调度时的回收。

应用服务授权、托管存储、桌面窗口系统和离线资源管理另行实现。跨源入口必须逐个声明允许来源；浏览器 CSP 与 iframe 策略仍然生效。
