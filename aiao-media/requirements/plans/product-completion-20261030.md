# 产品能力实施与验收

本计划保留 Web、Tauri、平台生图与计费、平台账号同步的实施历史。当前按 [D-19](../decisions.md#d-19登录用户经平台积分生图移除用户自配供应商) 提供平台账号与积分生图，模型凭据由服务端托管、积分由后台发放；充值、退款与价格体系继续按 [D-17](../decisions.md#d-17充值退款与价格体系暂缓平台生图已按-d-19-恢复为积分制) 暂缓。平台账号同步按 [D-16](../decisions.md#d-16统一使用平台-supabase) 使用统一 Supabase。故事状态以 YAML 为准；当前前后端与本地验收见[平台接线记录](platform-relay-credits-20261113.md)，正式双部署与桌面发行分别验收。旧 `/api/platform/` 实现和用户自配供应商保留历史，不作为当前产品入口。

## 实施选择

- 桌面首发 macOS 13+、Apple Silicon；复用现有 Tauri SQLite 与原生文件宿主。安装版与浏览器数据域独立，通过备份或显式同步迁移。首阶段手动安装升级，不启用应用内更新。
- 历史平台生图实现（D-17 暂缓）：Cloudflare Workers + SQLite Durable Object 持久队列与原子额度流水，R2 保存平台生成原图。单协调器串行预占、最多五个上游并发，免费与付费按接单顺序处理。当前日免费额度、每日预算默认零；未配置模型凭据或 R2 时拒绝接单。
- 历史支付实现（D-17 暂缓，未来商业模式须重新评审）：积分包与 Stripe Checkout。币种限使用两位小数的 USD/EUR/CNY/GBP/HKD；订单锁定购买时价格。原始 webhook 正文验签和金额核对后入账，跳转页面不入账。退款先冻结未消费积分，未知结果不解冻，支付服务按原幂等键核对。
- 每工作区只使用统一平台 Supabase，按平台账号与工作区隔离。登录不上传，首次同步另行确认。草稿、公开供应商配置与作品元数据走原有复制；原图通过平台私有 Storage 单独确认，供应商 Key 固定排除。移除未使用的自有项目接入及兼容入口。
- 远端当前元数据限 20,000 条、64 MiB 正文。停止同步不删除数据。远端删除为逻辑删除，传播 tombstone，继续保留冲突版本和同步日志；不是隐私数据彻底擦除。停止状态保存在设备上，本机副本与原图保留。
- 桌面模型凭据只在服务端，设备任务令牌不进入同步或备份；原生工作区指针、数据库、原图和格式兼容标记同在应用数据目录。清理 WebView 缓存不新建空库；更高标记拒绝打开。原生文件经保存对话框分块写入临时文件，完成后原子提交。

## Web 体积

原生选型入口按需加载数据库和文件依赖，图片传输模块改为按需加载后，补齐范围确认、分片进度及三种独立删除范围后的浏览器当前初始包为 612.33 kB。预算提醒为 510 kB，错误上限仍为 1 MB；本次构建保留超预算警告，没有将原生特权模块放入 Web 产物。两种产物目录分开，避免 Web 构建清理桌面文件。

## 运行与发行条件

平台账号配置与历史计费运维边界见[平台服务部署](../../deploy/supabase/platform-services.md)；当前平台生图部署按 D-19 的模型与积分契约，支付 API 继续关闭，历史计费配置不得作为启用步骤。桌面发行边界见[桌面说明](../../apps/desktop/src-tauri/README.md)。生产公开账号配置须显式使用目标平台项目，不自动发布本地 Supabase 或任意私有环境字段。没有执行本轮公网发布，也没有发起真实支付或真实供应商补验。
