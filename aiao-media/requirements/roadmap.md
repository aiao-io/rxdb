## 图片主路径

**选模板或写提示词 → 单模型生成 1 张 PNG/JPEG → 预览 → RxDB 本机保存 → 下载 → 反馈。** 本机功能无需登录或业务后台；供应商按本机配置直连或主动代理。

## 后续产品方向

[未来功能需求与目录规划](future-requirements.md) 汇总当前方向：Web 持续优化、Tauri 本地安装程序、Cloudflare 业务后端与管理页面（安全代理）及统一的平台账号同步；同时给出产品目标目录。平台图片服务、额度与计费按 [D-17](decisions.md#d-17当前平台免费暂缓独立平台图片服务与计费) 暂缓。首阶段代码与待验边界见[产品交付计划](plans/product-completion-20261030.md)。原自有项目接入按 D-16 撤销并移除；MEDIA-US-305 已部分接线，但真实 Storage 与跨设备尚未验收。

建议先保持 Web 与现有数据兼容、整理服务端/部署职责，继续完善默认免费供应商和本站代理任务。Tauri 和平台同步按各自前置并行推进，不依赖收费生图；独立平台生图与结算不在当前排期。详细依赖、验收目标和待定项见该文档；当前发布范围及故事状态继续按上文和 YAML 记录。

统一平台同步的目标流程为：**注册/登录平台账号 → 确认工作区与同步范围 → 元数据复制 → 确认历史/以后原图范围 → 上传 → 另一设备按需取回**。平台配置由部署方维护；元数据复制、原图远端保存与本机恢复各自验收，真实 Storage 与 Web/Tauri 通过后才交付完整流程。
