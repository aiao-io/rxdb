# 用户故事：多端草稿同步与冲突处理

## 作为/我想要/以便

**作为** 跨设备创作者

**我想要** 注册账号后通过 Supabase 同步草稿、作品元数据与供应商配置

**以便** 在多台设备继续创作，同时保留离线改动并看清本机文件的边界

## 范围边界

### In Scope

- 使用 `@aiao/rxdb-adapter-supabase` 与配套同步插件，在本机写入基础上同步；先验证发布版本兼容性、产品数据契约和应用接线，类型声明或上游故事 Done 不能算本仓已交付复制。
- 用户不启用同步时，本机读写不触发复制或远程数据上传；未配置账号服务时不连接 Supabase。显式配置账号后的 Auth 会话请求由 MEDIA-US-201 管理；启用复制前明确工作区/账号绑定与首次数据范围。
- 第一阶段同步草稿、作品的非敏感元数据和供应商配置；不发送 API Key、浏览器文件句柄、本地路径或可直接解引用的本地文件标识。本阶段固定排除 Key；后续如需同步凭据，另行明确范围与安全策略。
- 明确每类记录的稳定 ID、schema/revision、检查点、冲突策略和删除传播。离线修改重连后保留未确认变更，同记录修改/修改或删除/修改冲突保留可恢复版本，不仅按 updatedAt 静默覆盖。
- 删除使用可复制的 tombstone；重复推送、断网和重启可继续，不复活已确认删除的旧版本。D-06 确定首版无限期保留 tombstone、冲突原始双方和同步日志，不部署自动清理或 TTL。检查点不按时间过期；丢失或异常时显式重新扫描完整远程日志，保留本机未确认改动和推送水位，不重置远程序列。
- 同步状态可观察，区分待同步、进行中、已同步、冲突和失败。另一设备只有作品元数据时显示“本机无原图”，不提供虚假的本机预览或下载。
- 权限失效、协议不兼容或复制失败保留本机数据并暂停远程写入。同步不调用模型、不重新生成图片，不覆盖另一个账号或未绑定的本机工作区。

### Out of Scope

- 图片文件本体上传/下载、云作品备份、团队协作与 Electron 端同步。
- 自建 Bun API/PostgreSQL 同步协议；仅安装 RxDB 包就宣称 Supabase 同步可用。
- 未确定策略便同步供应商 Key；仅同步作品元数据就宣称原图已跨设备共享。

## 技术笔记

私有内容保持 `SyncType.None`；独立 DTO 数据库使用本仓 0.0.28 Supabase adapter、history 和 sync 插件，原生插件维护推拉日志与检查点。产品记录另外维护已确认的业务 revision，用于远程 CAS。首次确认前不打开复制数据库或上传本机内容。

真实产品套件已验证双独立存储副本、离线连续编辑和重开、双方冲突保留、明确决议、tombstone 不复活，以及作品信息设备显示“本机无原图”。供应商 Key、原图、文件路径与句柄固定排除。AC5 已通过真实本地服务的显式重扫验证：取消不扫描、从零重放旧日志、未上传修改遇远程删除保留双方、选择删除后重复扫描不复活且不增加业务 revision。扫描在账号/项目验证后、现有跨标签页锁内事务重置本机 pull 水位，保留 outbox、push 水位、业务 revision 和确认记录。D-06 不启用 TTL/清理；恢复依赖远程日志完整，不承诺日志截断或重建后的恢复。完整证据见[本地产品交付验收](../../plans/local-delivery-verification.md)。正式服务与域名仍单独验收。

2026-10-25 按用户本次结项指令，全部 AC 已验的本故事记为 Done；PR #154 仍未合并。状态口径见 [D-11](../../decisions.md)，原有验收与部署边界保留。
