# 用户故事：平台积分生图与额度

## 作为/我想要/以便

**作为** 登录平台账号的图片创作者

**我想要** 用平台积分生成图片，并能看到自己的余额与消费流水

**以便** 不再配置任何供应商或 Key，出图成本由平台统一承担与核算

## 范围边界

### In Scope

- 生成入口统一要求登录平台账号且有可用积分（[D-19](../../decisions.md#d-19登录用户经平台积分生图移除用户自配供应商)）；未登录时引导登录，余额不足时明确提示当前余额与不足数额，不调用上游。
- 模型与凭据由平台在服务端统一托管，用户不可见、不可配置；生成经 [MEDIA-US-109](MEDIA-US-109-relay-durable-task.md) 的服务端任务执行，本机交付见 [MEDIA-US-102](MEDIA-US-102-image-generation.md)。
- 积分账本由 [MEDIA-US-206](../account/MEDIA-US-206-credit-admin.md) 维护：余额、后台发放/回收流水与生成消费流水共用同一账本；用户可见本人余额与消费记录。
- 消费规则：任务结清（结果可取回）才扣减；明确拒绝、5xx、超时、断连与待核对不扣。同一任务标识去重不重复扣；预占与扣减服务端原子执行，防双花与负余额。
- 三画幅与参数契约沿用 MEDIA-US-102；失败与未知结果不自动重发、不连续扣费。
- 海外 Cloudflare 与国内自建（D-18）使用同一套积分契约与账本表结构；两侧分别验收。

### Out of Scope

- 充值、退款、价格体系与支付渠道（[MEDIA-US-205](../account/MEDIA-US-205-platform-billing.md) 继续按 D-17 暂缓）。
- 用户自配供应商、浏览器直连与按请求 Key（D-19 已移除）。
- 连续提交多张、服务端排队与任务列表。
- 把 D-17 移除前的平台 API 历史实现当作当前服务（保留代码与存量数据不代表服务仍开放）。

## 验收标准

| #   | 前置条件                         | 操作                | 预期结果                                                                     | 状态 |
| --- | -------------------------------- | ------------------- | ---------------------------------------------------------------------------- | ---- |
| 1   | 平台账号未登录或积分为 0         | 发起生成            | 引导登录；余额不足明确提示且不调用上游；不扣积分                             | ⬜   |
| 2   | 平台任务返回可交付结果           | 生成并查看余额/流水 | 任务结清才扣减，数额与配置一致；流水含任务、时间与余额变化，用户可见本人记录 | ⬜   |
| 3   | 上游拒绝、5xx、超时或结果待核对  | 等待结果并查看余额  | 不扣积分；不自动重发；待核对保持不确定，不连续扣费                           | ⬜   |
| 4   | 同一任务标识重发或两标签页同提交 | 重复接单            | 服务端原子扣减，只扣一次；负余额被拒                                         | ⬜   |
| 5   | 用户尝试配置或查看模型           | 打开创作与设置页    | 无供应商/Key 配置入口；平台凭据不出现在任务、日志、备份或界面                | ⬜   |
| 6   | 正式域名、真实平台账号与积分就绪 | 三画幅各生成一次    | 每次只调用一次上游，结果保存、刷新回读与精确下载一致，积分扣减与流水一致     | ⬜   |
| 7   | 国内自建部署就绪                 | 后台发放积分后生成  | 同一积分契约：后台发放可见、生成扣减一致，结果本机交付正常                   | ⬜   |

状态符号：⬜ 未开始 / ⚠️ 进行中或有保留 / ✅ 通过。

## 技术笔记

需求按 [D-19](../../decisions.md#d-19登录用户经平台积分生图移除用户自配供应商) 重新设计，实现尚未开始。服务端任务与刷新续接复用 [MEDIA-US-109](MEDIA-US-109-relay-durable-task.md)（已实现并通过本地测试，上游 Key 需改由平台凭据）；本机交付复用 [MEDIA-US-102](MEDIA-US-102-image-generation.md)。积分账本 schema、发放/回收接口与流水由 [MEDIA-US-206](../account/MEDIA-US-206-credit-admin.md) 定义，生成侧只消费余额。

D-17 移除前的历史实现（`platform-coordinator.ts` / `platform-api.ts` 及 `/api/platform/`）与验收证据见[产品交付计划](../../plans/product-completion-20261030.md)，不作为当前服务的依据；恢复时按重新评审的范围实现与验收。
