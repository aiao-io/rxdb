## 契约不变量

1. 所有解析/校验函数对非法输入返回结构化结果，不抛未捕获异常（spec FR-002）。
2. `structuralEqual` 是 query-builder 状态去重的唯一比较原语；其语义（键序无关）不得改变。
3. `EntityTableRecord`/`CellChangeEvent` 等表格类型是框架无关契约——Angular/React/Vue 组件与 core 之间只经这些类型通信。
4. 新增导出必须带 TSDoc 并通过 `pnpm audit:api-surface --check`。
