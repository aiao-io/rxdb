# Contract: `@aiao/rxdb-model-angular` 公开 API（移植基线）

**Status**: 契约 = 企业版 `@aiao/rxdb-model-angular@0.0.19` 公开导出面（已核对），适配项：`lucide-angular` → `@lucide/angular`；peer 依赖改为 workspace 策略；两个 barrel（entity-table/index、query-builder/index）的 `export * from '@aiao/rxdb-model'` 透传语义保留。门禁：`requirements/api-baseline/rxdb-model-angular.json`。

## Token 与主题

| 导出                              | 签名要点                                                                                                            |
| --------------------------------- | ------------------------------------------------------------------------------------------------------------------- |
| `ENTITY_TABLE_CONFIG`             | `InjectionToken<EntityTableConfig>`（core 类型，含 tooltipDelay 等）                                                |
| `QUERY_BUILDER_THEME`             | `InjectionToken<QueryBuilderTheme>`；`QueryBuilderTheme` = fieldSelector/operatorSelector/valueInput 三插槽组件类型 |
| `DEFAULT_QUERY_BUILDER_THEME`     | 默认三插槽映射                                                                                                      |
| `provideQueryBuilderTheme(theme)` | 返回 Provider                                                                                                       |

## 样式契约

- 组件类名遵循 Tailwind v4 + daisyUI v5 约定；包发布 `tailwind.css`（仅 `@source` 注册），**不发布编译 CSS**。
- 消费方接入：`@import '@aiao/rxdb-model-angular/tailwind.css';`（需自备 `@import 'tailwindcss'` + `@plugin 'daisyui'`）。
- 无样式管线的消费方渲染无样式组件——文档化行为。

## 契约不变量

1. Angular 包**不承载领域逻辑**：所有解析/校验/列构建/查询引擎均来自 `@aiao/rxdb-model`，组件只做信号桥接与 CDK/浏览器集成（spec 与 data-model 的边界不变量）。
2. React/Vue 绑定层（后续阶段）必须覆盖本契约全部能力面，公共 API 三端功能等价（宪法 III）。
3. 组件交互（行内编辑合并写入、undo/redo、筛选、级联新增）的可观察行为在 React/Vue 端必须一致。
