# 实施研究与决策

日期：2026-11-07。结论来自仓内当前实现、需求和已安装依赖源码。

| 决策                                           | 原因                                                     | 评估的替代方案                                                     |
| ---------------------------------------------- | -------------------------------------------------------- | ------------------------------------------------------------------ |
| React + Vite 多入口静态应用                    | 复用当前 React/Vite 工具链，内置应用生成真实独立文档     | Angular 外壳可行但不是公共能力对称的必要条件；三个外壳重复没有价值 |
| 沿用 packages/orbit                            | 已包含显式 ready、身份、来源、专属端口、取消、错误和释放 | 外部 Wujie 包违反用户明确要求；重写既有内核扩大风险                |
| IndexedDB 单事务提交                           | 元数据和字节必须一起成功；失败不宣称已保存               | localStorage 有同步阻塞与容量限制；内存回退违反持久化承诺          |
| Web Locks 独占 + BroadcastChannel 接管         | 同时启动不会双写；旧宿主须先协商所有脏状态再释放锁       | 仅用时间戳租约会受挂起影响；强制覆盖所有权会丢未保存内容           |
| 受控本地应用目录                               | 独立 Web 应用、无需远端服务；拒绝任意 URL                | 公开市场与不可信代码不在首版范围                                   |
| 完整构建资源清单 + service worker 原子缓存版本 | 资源下载不执行应用；仅完整版本可声明离线                 | 只缓存 HTML 或依靠 HTTP cache 无法证明完整性                       |
| 原始文件字节 + 乐观版本                        | 二进制导入导出保真，编辑器冲突不覆盖                     | 路径作为身份无法安全重命名；无版本写入会静默丢数据                 |
| 备份去除权限及敏感状态                         | 恢复数据不能扩展授权；格式及哈希校验先于提交             | 直接导入任意 JSON 无法保证完整性与原子性                           |

Nx 文档 MCP 返回 HTTP 500，改用当前已安装生成器与 CLI help 核实配置。Spec Kit feature.json 缺失已补显式目录，保留现有 012 分支及 001 规格路径，不复制规格。
