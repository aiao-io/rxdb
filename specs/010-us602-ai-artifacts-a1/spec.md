# Feature Specification: US-602 A1 发布知识的事实源与验证

**Feature Branch**: `codex/us602-a1`
**Created**: 2026-10-11
**Status**: Approved for implementation
**Input**: 用户批准优先完成无需人工设备、业务样本或发布操作的 US-602 A1。

## User Scenarios & Testing

### User Story 1 - 正确理解初始化与事务 (Priority: P1)

开发者从公开入口说明中获得正确的插件安装时机、连接初始化顺序与事务用法。

**Independent Test**: 打包后的声明保留三类插件说明；正确事务样例编译且能完成读写；错误用法经受控队列验证会重新排队。

**Acceptance Scenarios**:

1. **Given** 普通插件或贡献仓储、系统实体的插件，**When** 查阅初始化说明，**Then** 能区分合法晚装与必须早装的情况。
2. **Given** 一次事务，**When** 开发者遵循执行器样例，**Then** 读写属于同一事务且正常完成。

### User Story 2 - 选对包与组合 (Priority: P1)

开发者获得完整、一致、标明发布版本的包角色、后端槽位、框架对应与组合规则。

**Independent Test**: 覆盖首版所有情景的正反例，漏包、未知插件、槽位冲突或依赖循环都使门禁失败。

**Acceptance Scenarios**:

1. **Given** 本地、同步、查询缓存、图、树、框架绑定或独立编辑器情景，**When** 读取知识材料，**Then** 必需包与插件前置一致且无悬空引用。
2. **Given** 发布版本与工作区包含不同包，**When** 生成发布材料，**Then** 未发布包不进入安装清单。

### User Story 3 - 验证材料与可运行样例 (Priority: P2)

维护者自动发现知识漂移，并通过完全离线的最小样例证明安装、初始化与 CRUD 顺序正确。

**Independent Test**: 同输入生成两次字节一致；改动事实、模板或样例会使旧生成物检查失败；样例运行至正常退出。

**Acceptance Scenarios**:

1. **Given** 一份正确材料，**When** 修改源或生成物，**Then** 自动校验明确报错而不静默保留旧内容。
2. **Given** 无远端服务的环境，**When** 执行最小样例，**Then** 新建、读取、修改、删除均有断言且连接释放。

### Edge Cases

无发布标签、漏登记、重复包名、删除包残留、未知角色、共享实现占后端槽位、插件前置缺失、依赖成环、发布标签有包而当前树删除、生成物被手改均明确失败。

## Requirements

### Functional Requirements

- **FR-001**: 门禁范围包括所有非 private 包，API 基线范围保持现状；投递范围来自最近发布标签。
- **FR-002**: 人工事实只记录角色、槽位、宿主、框架与情景；安装边和插件注入边从其权威来源读取。
- **FR-003**: 首版覆盖纯本地、Supabase 同步、HTTP QueryCache、graph、tree、三框架绑定和独立 code-editor。
- **FR-004**: 漂移门禁定位包名、字段与来源，情景插件集合对注入前置闭合。
- **FR-005**: 材料携带发布版本和事实摘要，稳定排序且不含时间戳；消费目标缓存包含全部知识输入。
- **FR-006**: 最小离线样例包含安装清单、编译配置、实体与完整连接生命周期，并进入自动化验收。
- **FR-007**: 入口说明与打包声明表达相同约束，不改变公开签名和运行时行为。
- **FR-008**: 根审计入口、CI、发布前验证与现有文档门禁共享事实。
- **FR-009**: 故事与派生视图记录 A1 完成，其余阶段维持未完成。

### Key Entities

包事实、组合情景、插件前置、发布快照、材料摘要、可运行样例。

## Success Criteria

### Measurable Outcomes

- **SC-001**: 范围内包全部登记，全部首版情景具有可验证的正确组合。
- **SC-002**: 全部异常夹具非零退出，全部正确夹具与真实仓库审计通过。
- **SC-003**: 重复生成字节一致，手改或源变动均被检出。
- **SC-004**: 离线样例 CRUD 全部通过并正常退出；核心覆盖率维持四项 90% 以上。
- **SC-005**: 审计与生成目标实测小于 10 秒（不含已有构建）；运行时代码零变更。

## Assumptions

用户已授权 A1 的实现与常规验证。A2 peer 统一、B 站点投递、C Skill exporter 和对外发布不属于本次范围。无 UI 改动；三框架只登记等价组合，不改变各框架行为。无待澄清事项。
