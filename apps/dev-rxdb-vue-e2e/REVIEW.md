## 其余观察 / 测试缺口

- 现有 18 个 spec 的数量掩盖了按功能风险分布严重失衡：越接近本地数据和安全边界，覆盖越少。
- remote-cache 必须从网络层统计请求，不能只相信页面日志；encrypted 必须覆盖刷新后的真实持久化状态。
- 三个前端应用暴露近似功能，但 Vue E2E 没有复用 Angular/React 已有场景，跨框架行为没有统一验收标准。

## 验收条件

- OPFS、remote-cache、encrypted 各自具备至少一条成功路径和一条失败/边界路径，并能在对应缺陷实现上稳定失败。
- 首页导航测试必须发生真实交互，断言 URL 与目标页面；删除所有名不副实的空壳用例。
- 修复后执行 `pnpm nx e2e dev-rxdb-vue-e2e`，并记录浏览器对 OPFS 和加密持久化的运行条件。
