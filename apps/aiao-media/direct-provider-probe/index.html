01

连接供应商

描述你的图片

本次请求参数

兼容 images/generations 的 JSON 请求：n=1、quality=low、output_format=png。只验证支持这些参数的供应商/模型。

每次点击最多请求一张图片，使用你自己的供应商额度。失败或中断后不会自动重试。

这次验证什么？

验证静态页面 → 供应商 API → 浏览器读取真实图片。供应商 API 和图片地址需要支持跨域读取。

本页尚未接入 RxDB，结果仅在页面内存中，请及时下载。刷新或关闭页面后不会继续执行任务；停止等待不代表供应商取消或退款。
