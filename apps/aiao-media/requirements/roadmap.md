## 图片主路径

**选模板或写提示词 → 单模型生成 1 张 PNG/JPEG → 预览 → RxDB 本机保存 → 下载 → 反馈。** 本机功能无需登录或业务后台；供应商按本机配置直连或主动代理。

## 后续产品方向

[未来功能需求与目录规划](future-requirements.md) 汇总已确认的五个方向：Web 持续优化、Tauri 本地安装程序、Cloudflare 业务后端与管理页面（安全代理、免费/收费生图、拥堵排队提示）、自有 Supabase 同步、平台同步；同时给出产品目标目录。首阶段代码与待验边界见[产品交付计划](plans/product-completion-20261030.md)。MEDIA-US-304/305 当前只形成需求，不计为已实现。

建议先保持 Web 与现有数据兼容、整理服务端/部署职责；Cloudflare 免费生图需与持久任务、排队提示及最小后台一起形成完整流程，再扩展收费结算。Tauri 和两种同步目标按各自前置并行推进，不依赖收费生图。详细依赖、验收目标和待定项见该文档；当前发布范围及故事状态继续按上文和 YAML 记录。

Supabase 自动接入的目标流程为：**官方授权 → 选择项目 → 确认初始化 → 自动连接 → 确认历史/以后图片范围 → 后台上传 → 另一设备按需取回**。管理授权、初始化、元数据复制、原图远端保存与本机恢复各自验收；两条新增故事全部通过后才交付这个完整流程。
