当前重点是正式域名 `https://media.aiao.io` 的桌面图片交付、真实供应商和离线发布验收。账号/工作区、同步与跨用户后台本轮使用真实本地 Supabase；生产账号/后台保持未部署，属于后续范围。真实桌面 IME 按用户决定本轮跳过、保持未验，移动真机继续暂缓；旧 Bun API/PostgreSQL、SSR/BFF、音视频与 Electron 发行不作为本轮交付。

## 图片主路径

**选模板或写提示词 → 单模型生成 1 张 PNG → 预览 → RxDB 本机保存 → 下载 → 反馈。** 本机功能无需登录或业务后台；供应商按本机配置直连或主动代理。

2026-10-25 发布 version `cc8cc646-560e-4d36-b0cb-2e311a2d0e25` 已取得正式域名四路由/WASM/CSP 与缓存 46/46 摘要证据；实际断网、关闭旧页后的四路由新文档由 Service Worker 响应，profile/草稿保留。显式代理真实三画幅均各一次 HTTP 200，保存/刷新回读/精确下载通过；直连正方形无响应、保持未知未重发，另外两幅直连未尝试。MEDIA-US-102 AC7 仅代理部分已验，直连部分未完成，保持 ⚠️。三个成功结果均为 base64，真实 URL 路径、完整内容离线回读与发布更新/回退继续保留。Workers Free 当前 US$0 套餐与活动订阅已核对，证据范围见[正式交付验收](plans/public-delivery-verification.md)。
