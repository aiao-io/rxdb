# 产品能力实施与验收

本计划覆盖现有故事以及未来需求中的 Web、Tauri、平台生图与计费、两种同步目标。故事状态以 YAML 为准；代码、fixture、本地真实服务与正式发行分别验收，不以某一层通过替代其他层。

## 实施选择

- 桌面首发 macOS 13+、Apple Silicon；复用现有 Tauri SQLite 与原生文件宿主。安装版与浏览器数据域独立，通过备份或显式同步迁移。首阶段手动安装升级，不启用应用内更新。
- Cloudflare Workers + SQLite Durable Object 持久队列与原子额度流水，R2 保存平台生成原图。单协调器串行预占、最多五个上游并发，免费与付费按接单顺序处理。当前日免费额度、每日预算默认零；未配置模型凭据或 R2 时拒绝接单。
- 付费采用积分包与 Stripe Checkout。币种限使用两位小数的 USD/EUR/CNY/GBP/HKD；订单锁定购买时价格。原始 webhook 正文验签和金额核对后入账，跳转页面不入账。退款先冻结未消费积分，未知结果不解冻，支付服务按原幂等键核对。
- 每工作区一个同步目标；平台身份与自有项目按 origin 隔离会话。登录不上传，首次同步另行确认。只同步草稿、公开供应商配置和作品元数据，原图及供应商 Key 不进入复制。
- 远端当前元数据限 20,000 条、64 MiB 正文。停止同步不删除数据。远端删除为逻辑删除，传播 tombstone，继续保留冲突版本和同步日志；不是隐私数据彻底擦除。停止状态保存在设备上，本机副本与原图保留。
- 桌面供应商 Key 只在当前会话；原生工作区指针、数据库、原图和格式兼容标记同在应用数据目录。清理 WebView 缓存不新建空库；更高标记拒绝打开。原生文件经保存对话框分块写入临时文件，完成后原子提交。

## Web 体积

原生选型入口按需加载数据库和文件依赖，浏览器初始包约 503 kB。新增账号与平台入口后初始预算为 510 kB（错误上限仍为 1 MB），没有将原生特权模块放入 Web 产物。两种产物目录分开，避免 Web 构建清理桌面文件。

## 运行与发行条件

平台配置与运维步骤见[平台服务部署](../../deploy/platform-services.md)，桌面发行边界见[桌面说明](../../src-tauri/README.md)。生产默认继续关闭账号配置，不自动发布本地 Supabase 或任意私有环境字段。没有执行本轮公网发布，也没有发起真实支付或真实供应商补验。

真实供应商的既有未知请求按 D-02 保留，不更换 Key、清除尝试记录或自动重发。移动设备和正式签名、支付等外部条件缺失时保留未验状态，不用模拟证据关闭。
