# 用户故事：跨用户业务后台管理

## 作为/我想要/以便

**作为** 平台管理员

**我想要** 在后台管理用户、模板、供应商策略，并查看已上报的任务与用量

**以便** 无需逐个进入用户浏览器，就能维护公开内容、识别故障并核对平台实际收到的数据

## 范围边界

### In Scope

- 桌面 Web `/admin`；普通用户/匿名不能进入受保护数据操作。隐藏入口不能代替服务端授权。
- 使用 Supabase Auth 身份和服务端维护的管理员授权；部署平台登录不自动赋予产品管理员权限。首个管理员通过可信运维入口授予，禁止自助提权。
- 用户列表/详情、账号状态、封禁与解除封禁。全站平台维护不等于移除用户本机文件；保留最后一个有效管理员，账号物理删除暂不开放。
- 模板草稿、校验、版本、发布/撤回；已发布版本供普通用户读取。当前本机草稿/历史任务快照不被后台更新覆盖，资源不可用时保留静态目录。
- 供应商公共策略：规范化 HTTPS API 前缀、模型/参数兼容状态、直连/代理支持及启停。禁止代管用户 Key；代理允许列表的运行时来源与发布版本一致，不把仅数据库保存当作已生效。
- 任务按用户、模型、通道、时间与状态筛选；只展示用户确认上传或平台实际收到的记录，明确未上报的本机任务不可见。
- 用量按来源区分：已收到的应用请求计数、供应商回报用量、核验后的费用。缺少供应商证据时显示未知，不用图片张数推算已计费或把无限测试额度宣称为所有供应商免费。
- 管理操作保留操作者、对象、前后版本、操作时间和结果，不记录 Key/token/敏感响应；并发修改使用 revision/CAS，失败不虚报成功。

### Out of Scope

- 收集或查看用户供应商 Key、本机原图、OPFS 标识和未授权上传的私有内容。
- 充值扣费、自动计费、自动重发/重跑付费生成、任意 SQL/脚本控制台。
- 将管理员界面用于绕过普通用户 RLS，或恢复已删除而未备份的本机文件。
- 移动端后台适配、团队权限矩阵和账号物理删除。

## 验收标准

| #   | 前置条件                                   | 操作                                   | 预期结果                                                                    | 状态 |
| --- | ------------------------------------------ | -------------------------------------- | --------------------------------------------------------------------------- | ---- |
| 1   | 匿名、普通用户、管理员及伪造 user_metadata | 直达 `/admin` 并调用管理 API           | 仅有效管理员可读取/操作；伪造角色/owner 不能越权，浏览器产物无 service role | ✅   |
| 2   | 存在 A/B 用户与管理员                      | 管理员分页读取用户，普通用户请求同接口 | 管理员得到允许的账号字段；普通用户被拒，任务/凭据不随用户列表泄露           | ✅   |
| 3   | 管理员或普通账号                           | 封禁、解禁、尝试禁用最后一个管理员     | 授权操作生效；目标权限失效可验；最后有效管理员受保护，本机数据不清空        | ✅   |
| 4   | 模板草稿、非法字段或并发编辑               | 校验、发布、撤回和读取旧草稿           | 非法内容不能发布；普通用户只读有效发布版，历史草稿/任务不被覆盖，冲突可恢复 | ✅   |
| 5   | 已有供应商策略和运行中代理                 | 编辑前缀/模型、停用目标并再次请求      | 非法 URL 被拒，策略生效版本可见；代理遵从已生效策略，无用户 Key 入库        | ✅   |
| 6   | A 已上报任务、B 只有未上报本机任务         | 管理员筛选，A/B 越权请求对方记录       | 只显示真实接收记录及来源；普通用户隔离，B 未上报任务不被伪造为平台可见      | ✅   |
| 7   | 有应用计数，部分记录无供应商用量/费用      | 汇总和查看用量                         | 各来源单列；未知保留未知，不由张数推断费用，不触发模型调用                  | ✅   |
| 8   | 角色撤销、并发写入、网络错误或在途请求     | 继续操作并读取审计                     | 服务端拒绝失效角色；revision 冲突不覆盖，操作可追溯；日志/错误无 Key/token  | ✅   |

## 技术笔记

后台已接入本地产品服务：`/admin` 使用服务端 token 验证、实时管理员资格、CAS 和审计；模板与运行策略分开保存草稿/发布版，任务只经用户确认上报，按来源显示用量并保留未知。以上 AC 的 ✅ 仅表示真实本地服务与浏览器/Worker 验证通过；正式服务配置、生产发布与真实供应商兼容性仍单独验收。详见[本地产品交付验收](../../plans/local-delivery-verification.md)。
