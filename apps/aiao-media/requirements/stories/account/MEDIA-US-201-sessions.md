# 用户故事：Supabase 账号与资源授权

## 作为/我想要/以便

**作为** 需要多设备共享内容的创作者

**我想要** 可选地注册和登录 Supabase 账号，并授权同步自己的数据

**以便** 在其他设备使用相同账号，同时保留无需登录的本机创作能力

## 范围边界

### In Scope

- 使用 Supabase Auth 提供注册、登录、会话恢复和退出；账号是同步入口，本机编辑、供应商调用与本地作品访问不依赖登录。
- 明确定义账号与既有本机工作区的绑定、首次同步确认和切换流程；不静默合并多个本机工作区或把已有数据归给另一账号。
- 远程记录按可信 Supabase 用户身份授权，RLS 限制读取、修改与删除；不能相信客户端提交的 ownerId，不在浏览器放置 service role 凭据。
- 退出、会话过期与切账号停止对应复制和远程操作；迟到响应不能写入其他账号工作区。本机副本的保留/隔离与重新绑定策略在实施前明确，不默认删除本机原图。
- 鉴权错误、网络故障与同步错误有可恢复状态，不用登录成功冒充同步完成；不把供应商 API Key 当成 Supabase 凭据或默认上传。

### Out of Scope

- 自建密码哈希、PostgreSQL Cookie 会话、BFF、管理员代管供应商密钥或服务端生成授权。
- 登录后自动上传图片文件、账号团队管理、支付及本机离线登录授权。
- 仅有 SDK、配置或鉴权工具函数便宣称资源隔离已完成。

账号绑定采用本机独立工作区、用户确认后绑定远程工作区、按账号隔离复制；退出保留本机编辑，切账号不转属原副本。确定的设计和 B1–B6 实施步骤见[绑定计划](../../plans/account-workspace-binding.md)，本地产品接线与相关场景已验证，正式环境仍单独验收。

| #   | 前置条件                    | 操作                                  | 预期结果                                                     | 状态 |
| --- | --------------------------- | ------------------------------------- | ------------------------------------------------------------ | ---- |
| 1   | 干净浏览器，未配置账号服务  | 使用本机四页面                        | 无登录阻断，不创建 Supabase 连接或远程记录                   | ✅   |
| 2   | Supabase 项目和 Auth 已配置 | 注册、登录、刷新与退出                | 会话正确可恢复；退出清除本机会话、撤销刷新凭据并保留本机数据 | ✅   |

| 4   | 已有本机草稿/配置/作品      | 首次绑定账号并选择同步                | 用户确认范围，不静默合并、覆盖或上传 Key                     | ✅   |
| 5   | A 的同步仍在途              | 退出、过期或切换 B                    | A 的迟到结果不能进入 B 工作区，本机文件按明确策略保留        | ✅   |
| 6   | 鉴权服务断网或返回错误      | 登录或恢复会话                        | 错误可见，本机创作继续可用，不伪报登录或同步成功             | ✅   |

状态符号：⬜ 未开始 / ⚠️ 进行中或有保留 / ✅ 通过。

## 技术笔记

`SupabaseAuthClient` 与账号界面已接入注册、登录、服务端会话校验、刷新恢复、退出、待验证状态与跨标签事件。`aiao-media-e2e:local-first-e2e` 验证无账号配置和 Auth fixture；`aiao-media:supabase-e2e` 使用真实本地 Auth、邮件确认、生产静态包与 Chrome，覆盖阶段 A。会话和供应商 Key 分开管理，账号凭据不进入本机备份。

产品绑定与原生 RxDB 复制已接线。`aiao-media:product-test` 验证真实产品表的 RLS、所有权和 revision；`aiao-media-e2e:product-e2e` 验证确认/取消、独立副本、A/B 切换、离线恢复、冲突与在途响应隔离。登录本身不绑定、不上传，API Key 与原图不进入复制 DTO。完整证据与边界见[本地产品交付验收](../../plans/local-delivery-verification.md)。
