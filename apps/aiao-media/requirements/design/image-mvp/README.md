## 打开交互原型

直接在浏览器打开 [index.html](index.html)，不需要启动工程，也不发起生成 API。图片、字体和脚本均可从本目录读取；系统中文字体保证离线展示。`styles.css` 和 `prototype.js` 是评审用代码，不进入业务应用构建。原型中的 `textarea` 表达输入区的视觉布局；正式版复用项目现有 Tiptap 组件，规则见[灵感库 story](../../stories/generation/MEDIA-US-106-prompt-gallery.md)，原型不代替真实编辑器和供应商验收。

交互路径：

1. 在“发现灵感”筛选 / 搜索，点击图片卡片查看提示词和来源。
2. 点击“用这个灵感创作”，修改提示词，选择画幅。
3. 点击“生成图片”，演示等待和完成状态；点击“下载示例”可以取得参考文件。
4. 切换“我的图片”，演示复用提示词、下载和删除。
5. 点击反馈入口，选择感受、填写建议并复制文本；当前应用也保持这一反馈边界，未把复制成功显示为已提交。

设计状态可通过地址片段直接查看：`#discover`、`#studio`、`#library`、`#studio?state=empty`、`#studio?state=loading`、`#studio?state=error`、`#studio?state=unknown`、`#studio?state=storage-error`。原型的状态只保存在当前页面内存；刷新回到示例。原型中的状态只保存在当前页面内存；真实应用的草稿、任务、本机文件和反馈边界以当前 story 为准。

## 视觉与信息层级

浅米白背景、深绿色主操作、低饱和灰绿边界，营造安静的图片创作空间。图片是页面主体；导航和参数轻量，不出现音视频、模型市场或管理入口。

- 主色 `#244e3f`，文字 `#202b29`，背景 `#f8f8f4`，边框 `#e4e7df`。
- 发现页用三列图片卡片，手机两列；搜索和用途分类是唯一筛选层级。
- 生成页桌面左表单、右预览；手机先输入后结果，避免把主要表单挤到狭窄侧栏。
- 提示词区正式版使用现有 Tiptap，支持直接输入与模板行内参数，保留撤销/重做；不增加通用富文本工具栏。
- 表单只暴露提示词和画幅；单张、质量与模型固定。画幅以用户能理解的名称展示，尺寸由实际模型支持确定。
- 成功、服务失败、结果未知和本机保存失败分别表达。用户不需要理解服务端内部实现才能采取下一步操作。
- 作品库明确“当前浏览器 / 本机保存”，提供下载与复用。示例上的“演示”标识在正式实现中换为真实状态。

## 设计与实现之间的边界

本次交付 6 张参考图片、3 个主页面、5 个额外状态和3 张手机设计图。正式首发目标为 12 个静态模板；原型只有 6 个示例用于视觉评审。模板提示词为本次重写的演示文案，图片保持原样，来源和作者见 [SOURCES.md](assets/SOURCES.md) 与卡片详情。它们不是本项目真实生成结果。

原型顶栏的头像、邀请标签和保存状态只表达布局，不代表当前应用需要登录或已经完成真实供应商验收。
