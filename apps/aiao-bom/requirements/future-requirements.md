# Aiao BOM 后续产品范围

当前承诺见 stories；未建故事的方向不进统计、不承诺日期。优先以真实生产问题补足适用边界，避免把演示场景直接当成客户需求。

## 真实样本试用

由 [BOM-US-202](stories/production/BOM-US-202-real-sample-pilot.md) 承接。准入需要获准使用的脱敏数据、具体生产核对问题、人工基线和目标工程师。试用发现的缺口按所属领域建故事，保留尚未通过的 AC。

## 待范围评审的方向

| 方向                    | 解锁依据                                                                          | 需要的验收证据                                     |
| ----------------------- | --------------------------------------------------------------------------------- | -------------------------------------------------- |
| 正式发行与升级支持      | Cloudflare 静态发布由 BOM-US-002 承接，发行另需明确浏览器范围、数据保存与支持责任 | 受支持浏览器、版本与回滚策略、既有库升级记录       |
| 真实 ERP 文件与数据接入 | 明确供应商格式及业务键、单位、修订和来源契约                                      | 经授权的文件、逐行诊断和往返对账，不能只用生成样本 |
| 冷启动与全站离线        | 真实用户存在断网首访或离线刷新任务                                                | 生产产物首次加载、缓存升级和资源缺失的浏览器证据   |
| 真实规模的结构体验      | 获得有代表性的真实结构及操作路径                                                  | 受支持设备和浏览器的实际延迟、内存及可操作性记录   |
| 多人协作与权限          | 真实协作冲突、角色与审批需求                                                      | 身份、权限、并发冲突和同步策略的独立范围评审与验收 |

## 目录演进

沿用现有 platform / analysis / production / data 编号段；新增领域先在 CONVENTIONS 分配编号，再补 story、epic 和派生视图。研究与验证过程进入 plans；公共领域契约进入根需求并由 capabilities 引用，不把待定方向塞入已完成 AC。
