# 版本快照与日期比较

> 后续领域接入、迁移和最终验收见 [2026-11-14 收尾记录](completion-verification-2026-11-14.md)。本文件保留初轮实现及测量，未完成事项以收尾记录为准。

日期：2026-11-14，Asia/Shanghai。此项扩展独立 `aiao-bom-2` 工作台，不替换 `aiao-bom`，不连接或迁移 `dev-rxdb-bom`。

## 用户流程

1. 点击主界面的“版本 / 差异”。填写快照名称与评估日期，保存当前完整结构。
2. 编辑工作草稿，再保存一个版本。选择基准版本和目标版本进行比较。
3. 按新增、删除、改量、物料 / 变体变更、父项移动、用量状态或成本筛选，也可搜索件号、名称和位置身份。
4. 差异每页展示 100 项。导出文件包含全部差异，不受分页、搜索和类型筛选影响。
5. 导出目标快照 JSON，在同一数据集的独立工作区中先预览，再确认导入。重复身份不能覆盖原快照。

保存完整结构不采用主表的范围、市场或搜索筛选。若只需要一个子范围，应先从该范围建立工作草稿，再保存该草稿的完整结构。

## 语义

- `evaluationDate` 是用户标记的评估日期，不是从来源推断的制造生效期。`observedOn` 保留采集日期，`savedAt` 保留实际保存时间。
- 比较方向固定为“基准 → 目标”。同日、日期倒序均明确提示，不据此更改任何数据。
- 只比较同一 `datasetId` 和同一结构来源。系统分类、采购层级、CAD 场景与工作草稿分别保存。
- 发生位置 `key` 是对齐身份。同一物料的多个位置不合并；不同位置不能仅凭件号推断为同一逻辑行。
- 同一位置的物料或变体变化显示为换件核对，不等价于领域替代组的选用或分配。
- 数量、单位、确认状态、成本、标签、市场、类型、来源引用和模型节点变化均可查看。
- 所有数量和成本保持规范十进制字符串。仅当基准与目标的用量都已确认、非空且单位相同并已填写时计算直接用量差；调用公共 BOM Decimal API。
- 缺量、歧义量、参考量和缺少单位的行保留诊断。差异文件不作为完整 MRP 需求或发布合同。

## 存储与规模

使用现有独立库 `aiao-bom-2-workspace-v1` 的 `documents` 对象仓库，不改变数据库版本。

- `snapshot:<encoded-datasetId>:<encoded-id>`：完整快照。
- `snapshot-meta:<encoded-datasetId>:<encoded-id>`：不包含节点的版本目录条目。
- 两者在一个读写事务中以 `add` 追加，避免保存一半或被旧标签页覆盖。
- 初始化只读取目录；比较时才读取两个快照正文，避免把所有历史版本一次性装入内存。
- 切换数据集或比较条件后，过期读取、失败和保存反馈不能覆盖新状态。
- 重复身份、丢失父项、循环父链、非法日期、市场、模型索引和非规范数量会被拒绝。
- 单份快照最多 100,000 个位置，导入文件最多 50 MiB。父链校验与差异对齐按节点数线性执行，深链不使用递归。

## 验收

本轮最终通过 18 个测试文件、89 个单元 / 组件测试和 10 项端到端验收，端到端使用单个 Chromium worker、零重试。应用及 E2E 的 lint、类型检查、应用 spec-typecheck、生产构建和 Wrangler dry-run 均通过；ESLint 零警告。没有执行公网发布。

| 覆盖率     |   实测 | 门槛 |
| ---------- | -----: | ---: |
| Statements | 94.22% |  80% |
| Branches   | 86.94% |  80% |
| Functions  | 95.61% |  80% |
| Lines      | 98.17% |  80% |

真实主清单、采购层级和 CAD 数据均通过快照往返及自比较。数量边界额外补了空单位和纯空格单位的失败用例，确认修复前会错误计算数量差，修复后保留改量记录且差值为 `null`。

| --------------------------------------- | ---------: | ---------------: | ------: |

两种场景表格滚动均约 60 FPS，帧耗时 p95 为 16.67ms。纯表格 JS heap 增量 95.64 MiB，当前物化 1,000 行；100k 宽树的后续批次、末项搜索、点击与深链接通过。整车同屏连续选择仅请求一次模型，不重复绘制静止视角底图。

首次整车联动 p95 167.93ms 超过 150ms；第二次纯表格 / 同屏切换 p95 分别为 157.34ms / 150.34ms，也未通过。失败样本完整保留。最终在另一工作区的浏览器测试结束后独占复测，沿用原计时方式与门槛，全套通过；本次没有修改性能实现或放宽断言。机器负载会影响结果，一次复测不能证明此前所有超标都由外部负载造成。

50k 样本采用合成发生关系并复用 20 个真实 CAD 位置，不代表 50k 个不同几何资产；约 60 FPS 表示表格滚动，不表示软件渲染整车旋转帧率。模型反向拾取通过功能验收，尚未采集 20 次反向联动时延。
