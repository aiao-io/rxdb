# 后续候选范围

以下内容没有当前承诺故事，不计入 42 条故事统计，也不阻塞 M0～M2。只有出现明确用户任务并完成范围、风险和验收设计后才新建故事。

| 方向                               | 进入条件                                         | 必须补齐的边界                                                               |
| ---------------------------------- | ------------------------------------------------ | ---------------------------------------------------------------------------- |
| 任意第三方网页与公开应用市场       | 明确的非受信开发者分发需求与审核责任人           | 独立来源与强隔离模型、资源和服务代理、供应链审核；不能靠同源无界模型直接开放 |
| 账号、跨设备同步与团队协作         | 至少一个具体跨设备或多人任务、身份和远端服务方案 | 身份、权限、冲突、数据保留、文件字节同步、离线语义                           |
| Electron / Tauri 包装与本机能力    | 明确需要浏览器做不到的系统集成                   | 宿主桥接权限、原生文件、进程与更新签名；Web 桌面不因此直接执行任意程序       |
| 手机和平板专用交互                 | 确认触屏长时任务和最小工作区                     | 触屏窗口模型、虚拟键盘、手势冲突；不把桌面缩放当移动端完成                   |
| 应用计费、组织管理与企业分发       | 真实付费或组织治理需求                           | 授权、审计、支付和供应商服务验收                                             |
| 文件加密、在线备份与离线数据包签名 | 明确数据保护威胁模型与密钥管理方案               | 密钥恢复、加密范围、搜索能力、完整性与数据迁移                               |
| 更广浏览器支持                     | Firefox 或其他浏览器的具体用户需求               | 同样的运行内核与桌面旅程证据，不加入静默兼容降级                             |
