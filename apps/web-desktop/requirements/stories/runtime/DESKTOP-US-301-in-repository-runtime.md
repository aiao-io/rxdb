# 用户故事：Orbit 独立应用运行内核

## 作为/我想要/以便

**作为**平台维护者，**我想要**以 Wujie 为基线独立维护仓内 Orbit 隔离运行内核，**以便**能直接修复桌面问题并独立控制构建与发布。

## 范围边界

### In Scope

- 选定上游基线、保留来源与许可证、源码进入仓库。
- 拆离上游示例、桌面运行内核独立构建及既有消费迁移边界。

### Out of Scope

- 仅包装 npm 包、运行时从 CDN 下载上游内核、复制上游全部工程和历史兼容层。

## 前置与依赖

- 无应用内硬依赖。
