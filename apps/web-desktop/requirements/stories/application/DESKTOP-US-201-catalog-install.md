# 用户故事：应用目录与安装

## 作为/我想要/以便

**作为**桌面用户，**我想要**从审核过的目录选择并安装 Web 应用，**以便**安全识别应用来源并按需扩展桌面。

## 范围边界

### In Scope

- 内置应用与受控应用目录；详情、来源、版本、权限摘要。
- 安装、安装失败和重复安装处理。

### Out of Scope

- 开放第三方上传市场、付费交易、任意 URL 自动接入。

## 验收标准

| #   | 前置条件                   | 操作                     | 预期结果                                                               | 状态 |
| --- | -------------------------- | ------------------------ | ---------------------------------------------------------------------- | ---- |
| 1   | 桌面首次启动               | 打开应用目录             | 至少列出文件管理器、文本编辑器和设置，标明内置或可安装状态、来源与版本 | ⬜   |
| 2   | 可信目录有未安装的示例应用 | 查看详情并安装           | 显示所需桌面能力和离线支持；确认后应用出现在启动入口                   | ⬜   |
| 3   | 应用已安装                 | 再次安装同一 appId       | 不生成重复记录，展示已安装版本；更高版本进入更新流程                   | ⬜   |
| 4   | 安装资源拉取失败或校验失败 | 执行安装                 | 显示可诊断错误，不生成可启动的半安装记录，可显式重试                   | ⬜   |
| 5   | 安装请求正在进行           | 重复点击或离开目录再返回 | 复用同一安装任务并展示一致进度，不并发写入两份状态                     | ⬜   |
| 6   | 应用入口来自未批准来源     | 通过普通安装入口提交     | 明确拒绝且说明需要运营方纳入受控目录；不绕过策略打开                   | ⬜   |

状态符号：⬜ 未验证 / ⚠️ 进行中或有保留 / ✅ 有同层级证据。

验收证据：已进入产品实施；当前源码和自动化旅程见 [应用说明](../../../README.md)。仍需按 [分层验收台账](../../verification-report.md) 逐 AC 登记用例、构建版本、环境和结果，失败分支同样需要证据。

## 技术笔记

这里的安装是登记与准备 Web 资源，不执行本机二进制；内置应用同样通过应用协议运行。
