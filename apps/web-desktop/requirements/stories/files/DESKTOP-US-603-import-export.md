# 用户故事：本机文件导入与下载导出

## 作为/我想要/以便

**作为**带有现有文档的用户，**我想要**主动把本机文件带入桌面并把成果带走，**以便**避免文件被锁在浏览器存储中。

## 范围边界

### In Scope

- 文件选择和拖入导入、字节保存、同名决策、浏览器下载。
- 单文件上限 50 MiB；批次上限 100 文件或 200 MiB。

### Out of Scope

- 后台扫描本机磁盘、默认要求 File System Access API、暗中绑定本机目录。

## 验收标准

| #   | 前置条件                                       | 操作                         | 预期结果                                                               | 状态 |
| --- | ---------------------------------------------- | ---------------------------- | ---------------------------------------------------------------------- | ---- |
| 1   | 用户主动选择或拖入文件                         | 导入到指定虚拟目录           | 保留原始字节、名称与类型；导入后与原本机文件独立，不声称双向同步       | ⬜   |
| 2   | 目标目录已有同名文件                           | 导入                         | 允许跳过、保留两份或确认替换；未确认不覆盖，替换采用版本检查           | ⬜   |
| 3   | 单文件超过 50 MiB 或批次超过 100 文件、200 MiB | 选择导入                     | 写入前明确拒绝超限批次并说明限制，不部分导入后才报超限                 | ⬜   |
| 4   | 导入时读取失败、取消或存储额度不足             | 结束任务                     | 按批次原子提交规则保留旧状态，显示失败原因，不留下空文件               | ⬜   |
| 5   | 虚拟文件已保存                                 | 选择下载导出并确认浏览器下载 | 下载字节与保存内容一致；应用只保证交付下载，不能伪称用户磁盘已持久写入 | ⬜   |
| 6   | 导入 HTML、SVG 或脚本文件                      | 查看文件列表和预览           | 文件按数据保存，宿主不执行；主动下载保留用户选择                       | ⬜   |

状态符号：⬜ 未验证 / ⚠️ 进行中或有保留 / ✅ 有同层级证据。

验收证据：已进入产品实施；当前源码和自动化旅程见 [应用说明](../../../README.md)。仍需按 [分层验收台账](../../verification-report.md) 逐 AC 登记用例、构建版本、环境和结果，失败分支同样需要证据。
