# 用户故事：Windows 桌面与应用交互

## 作为/我想要/以便

**作为**习惯 Windows 的用户，**我想要**使用开始菜单、任务栏、窗口按钮和贴靠，**以便**快速找到应用并并行处理任务。

## 范围边界

### In Scope

- 开始菜单、任务栏分组、窗口右上角控制按钮。
- 任务栏预览、显示桌面、桌面工作区内的左右贴靠。

### Out of Scope

- 原生开始菜单替换、全系统 Win 键监听、执行 exe 文件。

## 验收标准

| #   | 前置条件                 | 操作                     | 预期结果                                                                       | 状态 |
| --- | ------------------------ | ------------------------ | ------------------------------------------------------------------------------ | ---- |
| 1   | Windows 模式且桌面就绪   | 打开开始菜单             | 可查看、搜索并启动已安装应用；空搜索有明确无结果提示                           | ⬜   |
| 2   | 应用正在运行             | 查看窗口和任务栏         | 窗口右侧依次为最小化、最大化或还原、关闭；任务栏可区分固定、运行与当前活动状态 | ⬜   |
| 3   | 同一应用有两个窗口       | 打开任务栏分组并选择窗口 | 显示两个独立标题与状态；选择后只恢复和激活指定窗口                             | ⬜   |
| 4   | 某应用最后一个窗口已保存 | 关闭该窗口               | 销毁对应实例，应用无剩余实例时运行标记消失；固定入口保留                       | ⬜   |
| 5   | 有可见窗口和已最小化窗口 | 执行显示桌面，再执行恢复 | 只暂时隐藏原可见窗口，恢复时不展开此前已最小化窗口                             | ⬜   |
| 6   | 窗口可调整大小           | 拖向工作区左侧或右侧     | 出现贴靠预览，释放后占据对应半区，任务栏和标题栏仍可操作                       | ⬜   |
| 7   | 桌面已就绪               | 查看任务栏系统区         | 显示真实本地时间、离线与必要状态；没有来源不明的假通知或不可操作图标           | ⬜   |

状态符号：⬜ 未验证 / ⚠️ 进行中或有保留 / ✅ 有同层级证据。

验收证据：尚无实现或产品验收证据；本轮只完成需求编写。实施时按 [分层验收台账](../../verification-report.md) 逐 AC 登记用例、构建版本、环境和结果，失败分支同样需要证据。
