# 用户故事：首次进入与交互模式选择

## 作为/我想要/以便

**作为**首次使用者，**我想要**直接进入可操作的桌面并选择熟悉的交互方式，**以便**无需安装或注册即可开始工作。

## 范围边界

### In Scope

- 首次进入、macOS / Windows 模式选择、可跳过的操作引导。
- 桌面空态、应用启动入口、受支持环境提示。

### Out of Scope

- 账号注册、联网身份体系、原生系统安装。

## 验收标准

| #   | 前置条件                   | 操作                         | 预期结果                                                                                         | 状态 |
| --- | -------------------------- | ---------------------------- | ------------------------------------------------------------------------------------------------ | ---- |
| 1   | 全新浏览器配置且环境受支持 | 访问桌面地址                 | 无需账号即可看到模式选择；可选择 macOS 或 Windows 后进入桌面                                     | ⬜   |
| 2   | 系统可识别宿主操作系统     | 首次进入且跳过选择           | macOS 宿主默认 macOS 模式、Windows 宿主默认 Windows 模式，其他宿主默认 Windows；始终允许手动修改 | ⬜   |
| 3   | 首次进入桌面               | 查看引导并启动内置文件管理器 | 能找到应用入口、打开首个窗口并关闭引导；完成状态被保存                                           | ⬜   |
| 4   | 没有打开的窗口             | 查看桌面空态                 | 显示应用入口与文件入口，不出现假文件、假通知或不可操作的装饰按钮                                 | ⬜   |
| 5   | 关键浏览器能力缺失         | 访问桌面                     | 展示缺失能力与支持范围，停止启动；不静默切换另一套运行时                                         | ⬜   |
| 6   | 首次引导已完成             | 刷新桌面                     | 保留用户选择且不重复弹出引导；设置中仍可重新查看帮助                                             | ⬜   |

状态符号：⬜ 未验证 / ⚠️ 进行中或有保留 / ✅ 有同层级证据。

验收证据：已进入产品实施；当前源码和自动化旅程见 [应用说明](../../../README.md)。仍需按 [分层验收台账](../../verification-report.md) 逐 AC 登记用例、构建版本、环境和结果，失败分支同样需要证据。

## 技术笔记

引导属于宿主，不作为一个子应用；模式默认值不等于浏览器快捷键可拦截。
