## 组合要求

- 两种交互模式 × macOS / Windows 宿主 × 各自支持浏览器均需验证；模式不能按宿主强制锁定。
- 三框架应用 × 同应用双实例 × 路由/样式/消息隔离均需组合验证。
- 离线可用、挂起、文件访问是显式声明能力，不是所有 Web 应用的默认保证。
- 受信应用隔离只承诺协议范围内的作用域与污染控制，不承诺任意不可信代码的强安全边界。
