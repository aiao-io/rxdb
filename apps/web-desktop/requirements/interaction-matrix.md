# macOS / Windows 交互行为矩阵

两种模式在任何受支持宿主上都可选择，共享应用、文件与偏好。模式是桌面内部的行为约定，宿主操作系统和浏览器仍决定保留键、全屏与剪贴板许可。责任故事是验收真相源，本表不独立维护状态。

## 外壳与应用入口

| 行为                     | macOS 模式                                       | Windows 模式                                 | 责任故事                      |
| ------------------------ | ------------------------------------------------ | -------------------------------------------- | ----------------------------- |
| 系统外壳                 | 顶部菜单栏、底部 Dock；桌面焦点显示桌面菜单      | 开始菜单、底部任务栏、状态区                 | DESKTOP-US-002、003           |
| 应用启动                 | Dock、应用启动器、搜索、文件关联                 | 开始菜单、任务栏、搜索、文件关联             | DESKTOP-US-201、203、206、404 |
| 固定入口                 | Dock 固定项，运行标记与固定独立                  | 任务栏固定项，运行分组与固定独立             | DESKTOP-US-206                |
| 已运行单实例应用再次启动 | 恢复已有窗口；无窗口运行实例建立新窗口；跨区定位 | 恢复已有窗口；跨区定位                       | DESKTOP-US-203                |
| 多实例应用               | 普通启动定位最近窗口，显式“新建窗口”创建实例     | 普通启动定位最近窗口，显式“新建窗口”创建实例 | DESKTOP-US-203                |
| 活动应用菜单             | 菜单栏跟随活动实例；无自定义菜单时有标准命令     | 窗口菜单或窗口操作菜单；命令协议相同         | DESKTOP-US-002、402           |
| 时间与状态               | 顶部系统区显示真实本地时间、离线与必要状态       | 任务栏系统区显示真实本地时间、离线与必要状态 | DESKTOP-US-002、003、502      |
| 桌面应用快捷方式         | 可双击启动应用；键盘有等价入口                   | 同左                                         | DESKTOP-US-206                |

## 窗口、关闭与退出

| 行为             | macOS 模式                                                                | Windows 模式                                   | 责任故事                 |
| ---------------- | ------------------------------------------------------------------------- | ---------------------------------------------- | ------------------------ |
| 窗口按钮         | 左上关闭、最小化、缩放                                                    | 右上最小化、最大化/还原、关闭                  | DESKTOP-US-002、003      |
| 普通拖动和缩放   | 标题栏拖动、边角缩放，遵守应用最小尺寸                                    | 同左                                           | DESKTOP-US-102           |
| 最大化           | 缩放按钮在普通和工作区最大化之间切换                                      | 最大化按钮或标题栏双击切换                     | DESKTOP-US-103           |
| 浏览器全屏       | 通过单独菜单动作，必须有用户激活并得到浏览器许可                          | 同左                                           | DESKTOP-US-103           |
| 左右贴靠         | 窗口操作菜单提供左右贴靠                                                  | 菜单及拖至工作区边缘预览并贴靠                 | DESKTOP-US-003、103      |
| 最小化           | 窗口隐藏但实例继续运行，Dock 提供窗口恢复入口                             | 窗口隐藏但实例继续运行，任务栏分组提供恢复入口 | DESKTOP-US-103           |
| 关闭一个窗口     | 先保护未保存内容；窗口移除，实例无窗口保留运行                            | 先保护未保存内容；该窗口实例销毁               | DESKTOP-US-104           |
| 关闭最后窗口     | 应用运行标记保留，Dock 应用菜单可发现全部运行实例，选择后为该实例重新开窗 | 该应用无剩余实例则运行标记消失，固定入口保留   | DESKTOP-US-002、003、104 |
| 退出应用         | 对全部相关实例先协商未保存内容，确认后全部销毁                            | 同左；从任务栏分组或应用命令可执行             | DESKTOP-US-104           |
| 多窗口退出时取消 | 一个窗口取消即停止整次销毁；已主动保存的内容不撤销                        | 同左                                           | DESKTOP-US-104           |
| 不响应关闭       | 5 秒无响应后提示并提供显式强制关闭，不自动丢弃内容                        | 同左                                           | DESKTOP-US-104、306      |
| 显示桌面         | 桌面菜单提供隐藏当前可见窗口及恢复                                        | 任务栏入口提供相同行为                         | DESKTOP-US-003、103      |
| 窗口概览         | 查看全部工作区的窗口并选择定位                                            | 同左；任务栏分组同时保留                       | DESKTOP-US-106、107      |

每个实例同时最多一个窗口。多窗口应用使用多个实例；同应用持久区可共享，内存状态和路由独立。macOS 模式关闭窗口后的隐藏实例仍在运行，不宣称暂停或释放其全部资源。放弃修改时由应用完成文档处置，再允许关闭；重新开窗不应把用户已明确放弃的草稿当作自动恢复内容。

## 键盘与焦点

| 操作                 | 桌面内部约定                                | 边界                                             |
| -------------------- | ------------------------------------------- | ------------------------------------------------ |
| 打开启动器           | 菜单入口；Ctrl+Alt+Space 为默认加速键       | 被宿主截获时以可见菜单完成                       |
| 打开窗口切换器       | 可见窗口入口；Ctrl+Alt+K 为默认加速键       | 切换器只涉及本桌面的窗口                         |
| 菜单移动、选择与取消 | 方向键、Enter、Escape                       | 不影响输入法组合和应用编辑操作                   |
| 移动、缩放、关闭窗口 | 标题栏窗口操作菜单与键盘动作                | 必须有可读反馈和可见焦点                         |
| 应用编辑快捷键       | 活动实例负责，例如保存与撤销                | 子应用需声明并限定作用域，不跨窗口广播           |
| 系统保留键           | Cmd+Tab、Alt+Tab、Win、Cmd+W 等仍由宿主决定 | 不承诺网页可拦截；关闭浏览器前提示也受浏览器控制 |

授权界面使用宿主系统层。应用自己的菜单、对话框和高 z-index 元素只能处于本窗口作用域，不允许覆盖系统授权或其他应用。应用内模态只限制自己的应用范围；系统授权模态限制相关桌面操作并在关闭后恢复原焦点。

## 模式切换与默认值

首次访问按宿主推断默认模式；识别不了时默认 Windows。用户明确选择后优先使用其偏好。模式不改变快捷键能否被操作系统拦截，也不改变应用身份。

切换时保持实例、路由、未保存内容和窗口正常边界，不重载应用。工作区变化后重新计算最大化和贴靠边界。macOS 模式存在无窗口运行实例时，切到 Windows 为这些实例建立窗口，让用户仍可访问并关闭；不得直接销毁它们。两种模式共享固定应用列表、主题和文件，不复制两份工作数据。
