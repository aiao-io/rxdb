# 用户故事：完整客户端国际化接入

## 作为/我想要/以便

**作为** 使用 Admin 应用模板构建多语言后台的开发者
**我想要** 外壳、自有页面和模型组件共用同一个国际化运行时
**以便** 中英文切换即时覆盖整个界面，并保留设备偏好、业务数据和空库恢复路径。

## 范围边界

### In Scope

- 复用 `@aiao/rxdb-i18n` 与 React 绑定，注册外壳、模型组件及应用自有中英文目录。
- 应用标题、描述、品牌、导航、已打开页签、偏好扩展、命令搜索和无障碍文案随语言更新。
- 起始页、全文搜索、实体失败态、备份恢复状态及已知错误码的中英文显示。
- 样例实体、字段与关系的显示名在表格、筛选、表单和搜索中一致翻译。
- 复用外壳 `app.locale` 的持久化和跨 Tab 通知；不初始化业务数据库来读取或写入语言偏好。
- 保留默认中文、既有数据标识、存储字段、业务值、未提交输入及恢复前不连接数据库的约束。

### Out of Scope

- 业务记录的多语言翻译、机翻或翻译工作流。
- 远端目录分发、额外偏好实体或另建同步通道。
- 小程序和其他宿主验收；另建 Angular / Vue 应用模板。
- 更改默认数据库名、迁移既有业务值或改写备份归档格式。

## 技术笔记

语言属于设备界面偏好。应用采用静态目录运行时，使用外壳已有 `app.locale` 恢复与分发语言；不调用持久化 i18n 的 `init()`，避免在恢复归档之前打开业务数据库。显示名是呈现元数据，不通过改写实体字段、默认值或数据库记录来翻译。
