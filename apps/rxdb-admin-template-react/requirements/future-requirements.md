# Admin 应用后续方向

## 当前孵化

先在本仓库形成可维护的应用模板基线，再通过一组新业务实体与一个非 CRUD 页面检验实际扩展成本。对应 [ADMIN-US-101](stories/domain/ADMIN-US-101-replace-sample-domain.md) / [ADMIN-US-102](stories/domain/ADMIN-US-102-custom-pages-navigation.md)，不先设计额外插件系统。

## 长期目标

未来可单独作为 Admin 启动项目模板。当前不研究或实施复制方案；在仓库内应用基线和实际业务扩展稳定、确有独立项目需要时，再评审工程边界、依赖与独立验收并建立故事。届时必须用同层运行证据证明可用，不能把当前 workspace 构建结果改写成独立工程已验证。

## 其他候选

账号认证、服务端权限、云端协作、桌面宿主及其他框架的完整应用模板，均需具体使用场景、能力缺口和独立验收范围后再立项。不随现有平台适配器或锁屏功能自动承诺。
