# AI Review 规则与记录

应用的代码问题不在这里新建：所有 Nx 项目（含应用）的新问题都写在仓库根 `requirements/reviews/<projectKey>/`，用仓库的 `ai-code-review` skill 评审与处理。规则、模板与状态转移只有根目录一份：`requirements/reviews/README.md`、`requirements/reviews/review.template.md` 与 `requirements/CONVENTIONS.md` 的「状态定义」。

本目录只保留应用早先写下的旧记录：按原 ID 就地处理，关闭后保留处置结果；需要迁移到根目录时保留原 ID 与来源，同一问题不维护两份可编辑副本。
