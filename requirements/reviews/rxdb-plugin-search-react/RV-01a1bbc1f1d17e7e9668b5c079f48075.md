# RV-01a1bbc1f1d17e7e9668b5c079f48075：search React/Vue README 把 Angular 的公开入口写成不存在的 injectSearch

## 问题与影响

使用者从 React 或 Vue README 的“三框架同功能对称”链接继续查 Angular 绑定时，会被指导使用 `injectSearch`。Angular 包实际公开的运行时入口是 `useSearch`，不存在 `injectSearch` 导出；照文档写跨框架示例会在导入或调用处失败，三端 API 对称说明也与实际入口不一致。这是文档消费路径的 P2 错误，绑定实现和 Angular 的实际导出本身正确。

## 证据与根因

冻结源码 SHA：`0ffa3c419fcc59dc3e13d695ca4658116134bfa0`。

- `packages/rxdb-plugin-search-react/README.md:70` 写成“Angular 用 `injectSearch`”。
- `packages/rxdb-plugin-search-vue/README.md:40` 写成同样的 `injectSearch`。
- `packages/rxdb-plugin-search-angular/src/index.ts:15` 实际导出的是 `useSearch`，文件 `inject-search.ts` 只是实现文件名；Angular README `:3` 也以 `useSearch()` 展示公开用法。

因此这不是命名风格差异：文档中的符号在包入口不存在，真实消费者无法按该说明导入。结论来自冻结源码的导出与文档文本，未执行示例、被评审代码、测试、网络请求或探针。

## 修复方向

把 React/Vue README 的跨框架说明统一改为 Angular 用 `useSearch`，并保留指向 Angular 包的链接。可增加一个文档消费者断言，确保跨框架入口名称与三个包的 `src/index.ts` 对齐。
