# RV-01a1bbc3584b71f9976a16a941475d46：Angular 与 Vue 文件搜索直接拼接无点扩展名，完整文件名无法命中

## 问题与影响

通过文件页创建 notes 和 .txt 后，持久化扩展名为 txt。搜索 notes.txt 或 .txt 时，两端把可搜索文本拼成 notestxt，刚创建的文件无法命中。普通/虚拟文件页的过滤结果因此为空；懒加载页高亮也漏命中。React 已统一用 formatFileName 补点。定 P2。

## 证据与根因

冻结源码：`0ffa3c419fcc59dc3e13d695ca4658116134bfa0`。

- `apps/dev-rxdb-angular/src/app/pages/file-manager/utils/tree-file.store.ts:215` 与 `apps/dev-rxdb-vue/src/app/composables/useFileManagerStore.ts:219` 创建文件时去掉扩展名前导点。
- Angular 在同文件第51行直接拼 name 与 extension；`apps/dev-rxdb-vue/src/app/composables/useFileManagerStore.ts:45`、第109行和第116行均同样缺少分隔点；`apps/dev-rxdb-vue/src/app/composables/useFileManagerLazyStore.ts:115` 也是此写法。
- 对照 `apps/dev-rxdb-react/src/app/pages/file-manager/utils/file-name.ts:8`。
- `/Users/jimmy/Documents/aiao/rxdb/.git/ai-review/v1/runs/full-main-20261108/parallel-001/web/repro-tree-state.mjs` 用冻结 Angular 状态库和真实 signals 断言 notes.txt 不命中；`/Users/jimmy/Documents/aiao/rxdb/.git/ai-review/v1/runs/full-main-20261108/parallel-001/web/repro-tree-search.mjs` 用冻结 Vue 状态库与真实 refs 断言查询后列表为空。未替换搜索实现，实体 IO 未参与。

## 修复方向

统一文件显示名/搜索文本函数，按存储约定补上一个点，覆盖带点/无点输入及普通、虚拟、懒加载页。
