# RV-01a1bbc358c170348e8014a35eddae39：Angular 文件树与 React 普通树搜索仍受折叠状态限制，命中子项不可见

## 问题与影响

已有 Docs/notes 子项，折叠 Docs 或刷新到默认折叠状态后搜索 notes，界面只显示不匹配的 Docs，真正命中的 notes 仍隐藏。Angular 普通/虚拟文件树，以及 React 普通/虚拟文件树和菜单树都可复现；用户必须手工展开搜索结果才能找到命中项。Vue 对照已沿搜索路径递归展示，定 P2。

## 证据与根因

冻结源码：`0ffa3c419fcc59dc3e13d695ca4658116134bfa0`。

- `apps/dev-rxdb-angular/src/app/pages/file-manager/utils/tree-file.store.ts:78` 传入原 expandedIds；`apps/dev-rxdb-angular/src/app/pages/file-manager/utils/tree-utils.ts:87` 只有 isExpanded 才递归。matchedFileIds 虽包含命中及祖先，也不会打开路径。
- `apps/dev-rxdb-react/src/app/hooks/useFileManagerStore.ts:105` 和第134行、`apps/dev-rxdb-react/src/app/hooks/useTreeMenuStore.ts:76` 和第102行、`apps/dev-rxdb-react/src/app/hooks/useTreeMenuVirtualStore.ts:56` 和第82行均在搜索过滤后只沿原展开集合递归。
- `apps/dev-rxdb-vue/src/app/composables/useFileManagerStore.ts:134` 对照明确在搜索时继续递归。页面实际渲染这些 store.treeNodes。
- `/Users/jimmy/Documents/aiao/rxdb/.git/ai-review/v1/runs/full-main-20261108/parallel-001/web/repro-tree-state.mjs` 的 Angular signals 用例，以及 `/Users/jimmy/Documents/aiao/rxdb/.git/ai-review/v1/runs/full-main-20261108/parallel-001/web/repro-tree-search.mjs` 的三个真实 React 渲染用例，均得到 visible=[p]、命中 c 不可见。

## 修复方向

搜索态临时打开命中节点的祖先路径，保留用户原展开集合供清空搜索后恢复；补充全折叠状态下的三端同场景对拍。
