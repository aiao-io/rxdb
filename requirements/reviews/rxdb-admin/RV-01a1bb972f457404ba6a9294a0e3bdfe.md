# RV-01a1bb972f457404ba6a9294a0e3bdfe：mac 快捷键冲突按其他平台计算，拒绝可用按键并放过重复 Cmd 键

## 问题与影响

mac 应用已有 Mod+K 时，注册实际不同的 Ctrl+K 会被拒绝；注册实际相同的 Meta+K 却被允许，按 Cmd+K 只触发先注册处理器，新处理器不可达。影响 mac 自定义快捷键，记 P2。

## 证据与根因

证据快照：`0ffa3c419fcc59dc3e13d695ca4658116134bfa0`。

`packages/rxdb-admin/src/shortcuts/registry.ts:133` 使用 formatCombo(..., other) 的文本判冲突，忽略实例 #platform。`packages/rxdb-admin/src/shortcuts/combo.ts:98` 实际匹配在 mac 将 Mod 解析为 meta。隔离复现 mac Registry：Mod+K 与 Meta+K 均注册成功，但 Cmd+K 只执行第一条；Ctrl+K 反而报 conflicts。

## 修复方向

按当前实例平台归一化实际 key 与修饰键后比较，不用显示文字判冲突。补 mac Mod/Meta 同键与 Mod/Ctrl 异键回归。
