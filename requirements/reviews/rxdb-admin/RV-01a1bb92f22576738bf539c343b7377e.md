# RV-01a1bb92f22576738bf539c343b7377e：aqua 被错误标为浅色，系统深色模式解析到未启用主题

## 问题与影响

应用按公开目录启用 light、aqua 两个主题并使用 system 偏好时，系统进入深色模式，外壳返回目录外的 dark 而非实际为深色的 aqua。data-theme 指向未启用主题，isDark 和主题循环也与实际样式不一致。仅影响包含 aqua 的特定配置，记 P2。

## 证据与根因

证据快照：`0ffa3c419fcc59dc3e13d695ca4658116134bfa0`。

`packages/rxdb-admin/src/theme/themes.ts:27` 使用 light('aqua')；preferred 依赖 dark 标志寻找明暗候选，`packages/rxdb-admin/src/theme/themes.ts:85` 因找不到深色候选回退到 dark。`packages/rxdb-admin/src/shell/create.ts:104` 将该结果接入 resolvedTheme，`:110` 用目录推导 isDark，`:262` 绑定到根属性。冻结 `pnpm-lock.yaml:12415` 锁定 daisyui@5.7.50；相同安装版本 theme/aqua.css 的 color-scheme 为 dark。隔离复现对所有主题目录逐项比对，仅 aqua 不符；pickThemes(['light','aqua']) 后 resolveThemeName('system',true,themes) 返回 dark，available=false。

## 修复方向

按锁定主题定义把 aqua 归到深色，并回归 system 深色解析、isDark 和主题循环。
