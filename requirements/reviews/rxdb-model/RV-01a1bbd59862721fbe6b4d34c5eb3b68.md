# RV-01a1bbd59862721fbe6b4d34c5eb3b68：表格系统剪贴板把 Infinity 写入 number 单元格

## 问题与影响

用户从系统剪贴板粘贴文本 Infinity 到 number 列时，表格生成 PendingWrite 并把非有限数写入数据；实体表单/严格字段校验拒绝这类值。粘贴路径因此绕过普通输入约束，记 P2。

## 证据与根因

证据快照：`0ffa3c419fcc59dc3e13d695ca4658116134bfa0`。

`table-clipboard.ts:24-27` 对 number 使用 Number 后仅 isNaN，Infinity/-Infinity 通过；`:333-335` 直接把 converted 放入 pending。真实 fake VTable 选区与 number 列复现：applySystemText(table, "Infinity", [{_propertyType:"number"}]) 返回一个 finite=false 的写入。

## 修复方向

使用 Number.isFinite 并与统一字段值校验保持一致，补 Infinity、-Infinity、NaN/超大数和普通有限数的剪贴板回归。
