# RV-01a1bbc359b07d0d963b05ab7dbd2774：React 与 Vue 懒加载树折叠后保留后代展开标记，重开时子树为空

## 问题与影响

依次展开父 p、子 c 看见孙 g，折叠 p 再重新展开 p；c 仍画成已展开，但 g 不显示，c 的监听也已清掉。用户要再折叠并展开 c 才能重新读到子树。React/Vue 的菜单和文件懒加载页都有同一问题，展开统计也保留已卸载的后代，定 P2。

## 证据与根因

冻结源码：`0ffa3c419fcc59dc3e13d695ca4658116134bfa0`。

- `apps/dev-rxdb-react/src/app/hooks/useFileManagerLazyStore.ts:199` 与 `apps/dev-rxdb-react/src/app/hooks/useTreeMenuLazyStore.ts:151` 仅从 expandedIds 删除当前 id；后续递归清理会退订后代并删除其数据，却不删除后代展开 id。
- `apps/dev-rxdb-vue/src/app/composables/useFileManagerLazyStore.ts:191` 与 `apps/dev-rxdb-vue/src/app/composables/useTreeMenuLazyStore.ts:158` 同样只删当前 id；后代集合用于删除订阅和节点，没有同步清理 expandedIds。
- 重开 p 只订阅 p 的直接子项。重新出现的 c 由残留标记显示展开，遍历却没有 c 的 childrenMap，故显示空树。Angular collapseNode 逐后代递归折叠作对照。
- `/Users/jimmy/Documents/aiao/rxdb/.git/ai-review/v1/runs/full-main-20261108/parallel-001/web/repro-tree-state.mjs` 分别加载四份冻结完整状态库，使用真实 React 渲染/Vue refs/RxJS，替换实体 IO。四种结果均为 childExpanded=true、grandchildVisible=false、childSubscribers=0。

## 修复方向

折叠子树时对同一个后代集合同时清理展开/加载状态、数据和订阅，或在重开时可靠重建后代监听。补 p→c→折叠p→重开p 的完整交互回归。
