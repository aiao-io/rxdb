# RV-01a1bbc35a2574978d0dcf30b97709b9：React 与 Vue 懒加载菜单全量展开后批量添加会清空全部监听

## 问题与影响

菜单懒加载页先点展开全部，再批量添加。expandAll 已以 ALL 查询替换根订阅，而批量添加成功收尾只保留名为 ROOT 的订阅，因而把唯一 ALL 也删掉；之后页面失去所有数据监听，后续单条写入或外部更改不会正常回流。React/Vue 同一正常操作序列触发，定 P2。

## 证据与根因

冻结源码：`0ffa3c419fcc59dc3e13d695ca4658116134bfa0`。

- `apps/dev-rxdb-react/src/app/hooks/useTreeMenuLazyStore.ts:352` 的 expandAll 先退订全部，再在第398行只登记 ALL；此时不存在 ROOT。
- 同文件第468行的 addManyMenus 收尾删除所有非 ROOT 订阅，之后只清理状态，没有 subscribeToRoot 或恢复全量模式。
- `apps/dev-rxdb-vue/src/app/composables/useTreeMenuLazyStore.ts:327` 与第427行有相同序列，第368行登记 ALL、第434行删除非 ROOT，未恢复数据源。
- `/Users/jimmy/Documents/aiao/rxdb/.git/ai-review/v1/runs/full-main-20261108/parallel-001/web/repro-tree-state.mjs` 用两端冻结完整状态库、真实 React/Vue/RxJS，先 expandAll 再成功 addManyMenus(1)，持久化替身发出新快照；收尾后两端 rootSubscribers=0、allSubscribers=0。

## 修复方向

批量添加收尾按照当前订阅模式恢复唯一有效数据源；不能假定 ROOT 始终存在。补展开全部后连续批量添加、单条创建和外部更新的用例。
