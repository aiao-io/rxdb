# RV-01a1bb73882375f788b736514246c731：React 与 Vue 的 Menu 生成示例未注册树生成器，切换后无法产出代码

## 问题与影响

在React或Vue生成器页面点击内置Menu标签，输入是页面自己提供的合法TreeRepository实体，生成阶段却必定因未注册TreeRepositoryGenerator而失败。React把异常吞成空文件列表，下载按钮仍可生成空ZIP；Vue会显示生成错误并禁用下载。Angular同一示例已正确注册树生成器。内置示例主操作在正常输入下不可用、三端能力不对称，定P1。

## 证据与根因

冻结源码：`0ffa3c419fcc59dc3e13d695ca4658116134bfa0`。

- `apps/dev-rxdb-react/src/app/pages/generator.tsx:23` 的Menu示例声明TreeRepository；`apps/dev-rxdb-react/src/app/pages/generator.tsx:49` 至 `apps/dev-rxdb-react/src/app/pages/generator.tsx:54` 新建普通生成器、直接exec，失败只返回空数组。
- `apps/dev-rxdb-vue/src/pages/GeneratorPage.vue:25` 提供同一repository；`apps/dev-rxdb-vue/src/pages/generator-state.ts:16` 至 `apps/dev-rxdb-vue/src/pages/generator-state.ts:21` 同样没有注册插件。
- `packages/rxdb-client-generator/src/core/RxDBClientGenerator.ts:263` 只内置RepositoryMethodsGenerator；`packages/rxdb-client-generator/src/generators/entity-definition.ts:69` 对没有注册的TreeRepository明确抛错。
- 对照 `apps/dev-rxdb-angular/src/app/pages/generator/generator.page.ts:105` 显式注册TreeRepositoryGenerator，随后才添加实体、exec。三端e2e仅验证标签/控件可见，未选择Menu并断言生成内容。

## 修复方向

React/Vue按Angular相同方式注册树生成器，保留插件包作为事实源；补点击Menu后的生成内容/下载产物断言，不能只断标签可见。
