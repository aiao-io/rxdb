# RV-01a1bb6641b2739d988e12cb3d8b3e31：主题 hook 各自持有独立状态，侧栏切换无法更新已挂载编辑器

## 问题与影响

独立运行React demo并打开/code-editor后，在侧栏切换主题，侧栏自己的hook将html data-theme改成dark，但编辑器使用的另一个hook仍保留auto/light，CodeEditor的theme prop不会更新。其它独立调用useTheme的组件也一样。Angular使用共享ThemeService、Vue使用模块共享ref，因此这个真实三端分歧发生在React。无界宿主广播回传可使各hook最终同步，普通独立运行没有这个通道。影响主题展示，定P2，不冒称影响数据写入。

## 证据与根因

冻结源码快照：`0ffa3c419fcc59dc3e13d695ca4658116134bfa0`。

- `apps/dev-rxdb-react/src/app/hooks/useTheme.ts:30` 在每次调用中独立useState，`apps/dev-rxdb-react/src/app/hooks/useTheme.ts:63` 的setTheme只更新本次setCurrentTheme、localStorage与可选宿主请求，没有同页共享状态或通知其它hook。
- `apps/dev-rxdb-react/src/app/components/AppThemeBtn.tsx:5` 和 `apps/dev-rxdb-react/src/app/pages/code-editor.tsx:16` 分别调用useTheme；编辑器在 `apps/dev-rxdb-react/src/app/pages/code-editor.tsx:21` 使用自己的currentThemeLightDark。
- `apps/dev-rxdb-react/src/app/app.tsx:67` 还创建第三份独立hook。现有useTheme.spec.ts只测单个renderHook，没有两个挂载消费者的同步断言。
- 对照 `apps/dev-rxdb-vue/src/app/composables/useTheme.ts:8` 的共享currentTheme与Angular单例服务，均不是每个消费者一份当前主题。

复现：`node /Users/jimmy/Documents/aiao/rxdb/.git/ai-review/v1/runs/full-main-20261108/parallel-001/web/repro-react-theme-instances.mjs`。从冻结源码加载实际hook，用实际React createRoot/act和Happy DOM同时挂载两个消费者，替换未接入的宿主通道。按钮setTheme(dark)后，实际button=dark、editor=auto、editorScheme=light、htmlTheme=dark。断言通过，未运行完整e2e。

## 修复方向

将React当前主题收口为共享store或context，使按钮、应用壳和编辑器读取同一份快照；保留宿主下发不回推语义。补独立运行、多消费者同时挂载时主题切换的回归。
