   2 
   3 **Research**: [../research.md](../research.md) D9、D10

   5 ## 1. core：`mountReplayer(host, options)`
   6 
   7 ```ts
   8 interface ReplayerOptions {
   9   readonly replay: ReplayManager;
  10   readonly sessionId: string;
  11   readonly initialTime?: number; // 相对会话起点的 ms；默认 0
  12   readonly onTimeChange?: (timeMs: number) => void;
  13   readonly onCommitRestore?: (event: ReplayerCommitRestoreEvent) => void;
  14 }
  15 
  16 interface ReplayerCommitRestoreEvent {
  17   readonly marker: ReplayCommitMarker;
  18   readonly result: WorkingTreeRestoreResult | { readonly ok: false; readonly reason: 'error'; readonly error: Error };
  19 }
  20 
  21 interface ReplayerHandle {
  22   update(options: Partial<Pick<ReplayerOptions, 'replay' | 'sessionId' | 'initialTime'>>): void;
  23   play(): void;
  24   pause(): void;
  25   seek(timeMs: number): void;
  26   destroy(): void;
  27 }
  28 
  29 function mountReplayer(host: HTMLElement, options: ReplayerOptions): ReplayerHandle;
  30 ```
  31 
  32 - `update()` 只在 `replay` 或 `sessionId` 变化时重新加载；只改 `initialTime` 等价于 `seek()`。
  33 - `play` / `pause` / `seek` 在非就绪态是空操作（加载完成后按最后一次 `seek` 的时刻落位）。
  34 - `destroy()` 幂等；之后的任何调用都是空操作。
  35 - `restoreToCommit()` 抛错（如 `working_tree_unavailable`）时 `result` 为 `{ ok: false, reason: 'error', error }`，状态区显示错误消息。

  52 ## 3. 三框架组件
  53 
  54 | 项       | Angular `@aiao/rxdb-plugin-replay-angular`                           | React `@aiao/rxdb-plugin-replay-react` | Vue `@aiao/rxdb-plugin-replay-vue` |
  55 | -------- | -------------------------------------------------------------------- | -------------------------------------- | ---------------------------------- |
  56 | 组件     | `ReplayerComponent`，选择器 `ao-replayer`                            | `Replayer`                             | `Replayer`                         |
  57 | 输入     | `replay` / `sessionId`（`input.required`）、`initialTime`（`input`） | 同名 props                             | 同名 props                         |
  58 | 时刻变化 | `aoTimeChange`（`output<number>`）                                   | `onTimeChange(timeMs)`                 | `time-change`（`emit`）            |
  59 | 恢复结果 | `aoCommitRestore`（`output<ReplayerCommitRestoreEvent>`）            | `onCommitRestore(event)`               | `commit-restore`                   |
  60 | 命令     | 组件实例方法 `play()` / `pause()` / `seek(ms)`                       | `ref` 句柄 `ReplayerRef` 的同名方法    | `defineExpose` 同名方法            |
  61 | 宿主     | 组件宿主元素内一个 `div`                                             | 一个 `div`                             | 一个 `div`                         |
  62 | 卸载     | `DestroyRef` → `destroy()`                                           | effect 清理 → `destroy()`              | `onBeforeUnmount` → `destroy()`    |
  63 
  64 再导出：三个包都再导出 `ReplayerCommitRestoreEvent` 类型与 `replayRestoreHint`，不再导出其他 core 成员。

  66 ## 4. parity 契约（`@aiao/rxdb-plugin-replay/testing`）
  67 
  68 `replayerParityCases` 是一组与框架无关的用例描述，三个包的组件测试各自把它翻译成本框架的挂载 / 改输入 / 调命令，`mountReplayer`
  69 用 `vi.mock` 打桩：
  70 
  71 1. 挂载 → `mountReplayer` 被调用一次，`host` 是组件内的元素，`replay` / `sessionId` / `initialTime` 原样传入；
  72 2. 改 `sessionId` → `update({ sessionId })` 一次，不重新 `mountReplayer`；
  73 3. 改 `initialTime` → `update({ initialTime })`；
  74 4. 桩里触发 `onTimeChange(1234)` → 框架输出收到 `1234`；
  75 5. 桩里触发 `onCommitRestore(e)` → 框架输出收到同一个 `e`；
  76 6. 调 `play` / `pause` / `seek(500)` → 句柄同名方法各一次，`seek` 参数 `500`；
  77 7. 卸载 → `destroy()` 一次。
