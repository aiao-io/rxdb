# RV-01a1bb8c33b07a47a1098f920cbaf5d3：Vue 加密页初始化晚于卸载完成时，遗留锁状态监听和数据库读取

## 问题与影响

进入加密页后，在数据库连接或加密元数据查询仍等待时快速导航离开，卸载回调只清理当时尚为空的订阅。异步初始化随后恢复并创建永久存活的锁状态监听。以后解锁数据库会让已经离开的页面再次读取全部加密用户；反复快速进入退出会累积监听和读取。生命周期跨越了页面卸载，定 P2。

## 证据与根因

冻结源码：`0ffa3c419fcc59dc3e13d695ca4658116134bfa0`。

- apps/dev-rxdb-vue/src/pages/EncryptedPage.vue:60 的 onMounted 先等待 connect，再调用 bindEncryption；没有有效期或取消检查。
- apps/dev-rxdb-vue/src/pages/EncryptedPage.vue:47 又等待 isInitialized，随后在第49行无条件订阅 lockChange$。第69行的 onUnmounted 只对现有 lockSub 调用 unsubscribe，无法清理未来才建立的订阅。
- apps/dev-rxdb-vue/src/pages/EncryptedPage.vue:51 的解锁回调继续调用 loadUsers；第32行真实依赖 entityManager 的仓库读接口。
- packages/rxdb-adapter-sqlite-core/src/sqlite-core.types.ts:110 明确 isInitialized 是 Promise；packages/rxdb-adapter-sqlite-core/src/RxDBAdapterSqliteBase.ts:587 返回适配器持有的 Keyring 锁状态流，页面不会拥有该流的销毁权。
- React 对照 apps/dev-rxdb-react/src/app/pages/encrypted-lifecycle.ts:24 在 Promise 恢复后检查 active，并在清理时失效；对应单测覆盖连接 Promise 晚于销毁恢复的边界。

有界诊断 /Users/jimmy/Documents/aiao/rxdb/.git/ai-review/v1/runs/full-main-20261108/parallel-001/web/repro-vue-encrypted-lifecycle.mjs 读取并转译冻结的完整 Vue script，替换框架生命周期入口和数据库 IO，使用真实 RxJS Subject。顺序为 mounted→unmounted→连接恢复→unlock，断言订阅数为1、卸载后读请求为1。验证了原异步控制流，没有冒称真实浏览器或完整适配器集成测试。

## 修复方向

在卸载时标记失效；在两个异步边界之后、建立订阅和更新页面状态之前核对有效期。保持已建立订阅的清理。补充初始化晚于卸载完成的生命周期测试，与 React 的取消语义对齐。
