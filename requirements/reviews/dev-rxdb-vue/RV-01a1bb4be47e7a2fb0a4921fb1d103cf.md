# RV-01a1bb4be47e7a2fb0a4921fb1d103cf：Vue 历史侧栏媒体查询监听跨页面卸载仍存活

## 问题与影响

Todo、菜单、文件管理页每次 setup 都调用 useShowHistory。组合式函数为 matchMedia 注册匿名 change 回调，却从不在组件卸载时移除。反复进入和离开这些路由，会按挂载次数留下媒体查询监听与闭包持有的 ref；窗口跨越 768px 时已卸载页面仍被回调更新。React 对应 hook 返回清理函数，Angular 在 DestroyRef 中清理。属于随导航累积的资源泄漏，定 P2。

## 证据与根因

冻结快照：`0ffa3c419fcc59dc3e13d695ca4658116134bfa0`。

- `apps/dev-rxdb-vue/src/app/composables/useShowHistory.ts:11` 直接给新 MediaQueryList 添加匿名 change 回调；整个函数没有 removeEventListener 或生命周期清理，也没有保存可移除的回调引用。
- `apps/dev-rxdb-vue/src/pages/TodoPage.vue:28` 在 setup 中调用该函数；`apps/dev-rxdb-vue/src/router/index.ts:32` 把页面作为路由组件加载。菜单和文件管理六个页面也使用相同组合式函数，跨页面访问会反复执行。
- Todo 自己的 `apps/dev-rxdb-vue/src/pages/TodoPage.vue:181` 清理历史订阅和拖拽控制器，但拿不到 useShowHistory 内部匿名监听，所以不能补偿。
- 对照 `apps/dev-rxdb-react/src/app/hooks/useShowHistory.ts:14` 返回 removeEventListener；`modules/angular-todo/todo-page/todo.page.ts:176` 将媒体监听移除登记到 DestroyRef。

有界复现：`node /Users/jimmy/Documents/aiao/rxdb/.git/ai-review/v1/runs/full-main-20261108/parallel-001/web/repro-vue-todo-lifecycle.mjs`。repro-vue-todo-lifecycle.mjs 使用实际 Vue createRenderer 挂载/卸载三个最小组件，每个组件执行冻结的 useShowHistory；卸载后假 MediaQueryList 仍有3条监听，派发 change 后3个已卸载状态全部变化。没有启动浏览器或真实数据库。

## 修复方向

保留 MediaQueryList 和具名回调，并在组合式函数所属组件/作用域销毁时对称 removeEventListener。对 Todo/菜单/文件页补重复挂载卸载测试，验证活监听数量回到挂载前、卸载后不再修改旧 ref。
