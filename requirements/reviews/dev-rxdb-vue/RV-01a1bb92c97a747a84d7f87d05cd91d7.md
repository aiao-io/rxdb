# RV-01a1bb92c97a747a84d7f87d05cd91d7：Vue 实体详情页保存或取消后跳到首页，未返回原实体列表

## 问题与影响

通过深链进入 /entities/public/Todo/abc 后点击保存或取消，实际导航到 /home，原实体列表丢失。详情业务写入可能成功，但页面声称的返回列表行为失效；Angular/React 的对应页返回原列表。限定深链详情入口，定 P2。

## 证据与根因

冻结源码：`0ffa3c419fcc59dc3e13d695ca4658116134bfa0`。

- `apps/dev-rxdb-vue/src/pages/entities/EntityDetailPage.vue:20` 与第25行均调用 router.push 的相对路径父目录。Vue Router 对此按当前路径所在目录再退一级，得到 /entities/public/，并非 /entities/public/Todo。
- `apps/dev-rxdb-vue/src/router/index.ts:121` 声明详情路由为四段扁平路径；文件末尾兜底路由将未匹配地址重定向 /home。
- `apps/dev-rxdb-vue/src/pages/entities/entity-pages-construction.spec.ts:148` 仅 mock push 并检查参数文字，没有用真实路由解析其目标。
- 对照 `apps/dev-rxdb-react/src/app/pages/entities/entity-detail-page.tsx:22` 显式选择 path 相对语义，以及 Angular 的 ActivatedRoute 相对导航。

有界诊断 `/Users/jimmy/Documents/aiao/rxdb/.git/ai-review/v1/runs/full-main-20261108/parallel-001/web/repro-vue-entity-return.mjs` 从冻结 SFC 提取原保存/取消函数，使用已安装的真实 Vue Router、MemoryHistory 和与生产一致的详情/列表/兜底路由形状。两次回调实际均导航 /home；外部表单和数据库 IO 未参与。

## 修复方向

使用 entity-list 命名路由和当前 namespace/name 参数返回列表。测试用真实 MemoryHistory 核对最终路径，覆盖保存和取消；勿只断言传入 push 的字符串。
