# RV-01a1bb43dd4f70b0bbfd07aa13521f96：图查询文档把 Promise 静态 API 当成 Observable，示例无法运行

## 问题与影响

按模型查询章节复制图查询示例时，读者会调用 firstValueFrom(Person.findNeighbors(...))、firstValueFrom(Person.countNeighbors(...)) 或 firstValueFrom(Person.findPaths(...))。真实的无 $ 方法返回 Promise，firstValueFrom 要求 Observable，TypeScript 会拒绝该输入；通过 JS 或宽类型运行时抛 TypeError: source.subscribe is not a function。三个图查询页均将此写成基本用法，查询总览又承诺图静态方法全部返回 Observable，导致用户无法依文档完成图查询。限定在文档接入路径，按 P2 记录。

## 证据与根因

冻结快照：`0ffa3c419fcc59dc3e13d695ca4658116134bfa0`。

- `website/docs/model-query/README.md:7` 将普通、树、图静态查询统一说成 Observable。
- `website/docs/model-query/findNeighbors.md:3`、`website/docs/model-query/findNeighbors.md:18` 宣称无 $ 名称返回 Observable，`website/docs/model-query/findNeighbors.md:49` 交给 firstValueFrom。`website/docs/model-query/countNeighbors.md:3`、`website/docs/model-query/countNeighbors.md:24` 与 `website/docs/model-query/findPaths.md:3`、`website/docs/model-query/findPaths.md:47` 使用相同错误契约。
- `packages/rxdb-plugin-graph/src/GraphRepository.ts:96`、`packages/rxdb-plugin-graph/src/GraphRepository.ts:119`、`packages/rxdb-plugin-graph/src/GraphRepository.ts:155` 的三个无 $ 方法实际返回 firstValueFrom(this.<method>$(...))，即 Promise；同文件保留带 $ 的 Observable 入口。
- 这不是「仓库是 Promise、静态方法另包 Observable」：`packages/rxdb/src/entity/entity-manager.ts:168` 至 `packages/rxdb/src/entity/entity-manager.ts:175` 绑定静态方法时调用仓库同名方法、透传全部参数并原样返回结果。`packages/rxdb-plugin-graph/src/GraphEntityBase.ts:43`、`packages/rxdb-plugin-graph/src/GraphEntityBase.ts:68`、`packages/rxdb-plugin-graph/src/GraphEntityBase.ts:98` 也将静态无 $ 方法声明为 Promise，生成器 GraphRepositoryGenerator 的 resultWrapper 同样是 Promise。

有界复现：`node /Users/jimmy/Documents/aiao/rxdb/.git/ai-review/v1/runs/full-main-20261108/parallel-001/web/repro-graph-doc-observables.mjs`。脚本读取冻结 GraphRepository 实现，替换非本问题的底层数据源为 of([])/of(0)，调用实际三个无 $ 方法后交给实际 RxJS firstValueFrom。三个结果均为 Promise，三个调用均抛上述 TypeError。没有启动真实数据库或浏览器。

## 修复方向

图查询示例选择 await Person.findNeighbors(...)，或 firstValueFrom(Person.findNeighbors$(...))；countNeighbors / findPaths 同样区分两种入口。修正查询总览，核对生成器、基类、仓库与示例方法名；将这些可复制代码块纳入会验证返回类型的文档测试。
