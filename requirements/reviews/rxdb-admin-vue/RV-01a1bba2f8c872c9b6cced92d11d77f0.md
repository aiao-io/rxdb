# RV-01a1bba2f8c872c9b6cced92d11d77f0：无菜单匹配页的一级标题在品牌切换语言后保持旧文案

## 问题与影响

宿主以 brand.titleKey 提供多语言品牌，当前地址不在菜单里且 menu/url 引用未变时，切换语言后 shell.brandTitle 已变、品牌区和其它翻译已更新，视觉隐藏 h1 仍为旧语言。影响读屏页面标题，记 P2。

## 证据与根因

证据快照：`0ffa3c419fcc59dc3e13d695ca4658116134bfa0`。

`packages/rxdb-admin-vue/src/layout/admin-layout.vue:41` 的 computed 仅跟踪 props.menu/url，fallback shell.brandTitle 来自普通 getter，未读取 shell.text 的 Vue ref；`:144` 模板读取缓存的 computed。执行源文件该 computed 声明：先读取为工作台，await i18n.setLocale(en) 后 shell.brandTitle=Workbench，而 pageTitle.value 仍为工作台。Angular `packages/rxdb-admin-angular/src/layout/admin-layout.component.ts:85` 同形 computed 也未依赖 text 修订；本次没有挂载 Angular 验证，交主任务继续确认。React AdminLayout 由 useAdminText 订阅导致 render 重算，无此缓存路径。

## 修复方向

让 pageTitle 的计算读取文本修订（沿用三端已有桥接），补菜单无匹配且品牌 titleKey 切换语言回归；同时核对 Angular 对应计算。
