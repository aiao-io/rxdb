# RV-01a1bbbd66797d02b02bd2e15845a7d2：符号预检遗漏动态 EntityBase 导入，生成重复绑定的非法模块

## 问题与影响

实体名 EntityBase 且继承核心 EntityBase 时，addEntity/exec 均成功，输出同时 import EntityBase 和 let EntityBase，Node 无法加载。源码通过别名导入核心基类后定义同名实体是可表达的输入，生成器需要拒绝冲突或给导入起别名。特定命名触发，记 P2。

## 证据与根因

证据快照：`0ffa3c419fcc59dc3e13d695ca4658116134bfa0`。

`packages/rxdb-client-generator/src/core/generated-symbols.ts:10` 的固定导入集合不包含 EntityBase；`:145` 的导入符号预检也未登记按元数据/Repository 方法动态加入的基类绑定。`packages/rxdb-client-generator/src/core/RxDBClientGenerator.ts:85` 的 RESERVED_ENTITY_BINDINGS 同样未包含它。实际输出 import { Entity, EntityBase, __decorateClass } 后声明 let EntityBase = class extends EntityBase {}，exec 成功，Node import 抛 Identifier 'EntityBase' has already been declared。

## 修复方向

预检覆盖实际类型与运行时导入绑定，或统一别名化冲突导入；补 EntityBase 及插件自带基类名冲突的生成与加载回归。
