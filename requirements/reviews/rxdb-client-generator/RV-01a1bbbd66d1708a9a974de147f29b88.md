# RV-01a1bbbd66d1708a9a974de147f29b88：空 KeyValue schema 生成未声明的精确接口和未导入的通用类型

## 问题与影响

属性 type=keyValue、properties=[] 被生成器接受；声明层属性使用 KeyValue 却没有导入，规则层又引用根本没有声明的 EmptyConfigDataKeyValue，导致生成的声明不能通过消费方类型检查。已有空 schema 用例只验证规则存在，未验证完整声明，记 P2。

## 证据与根因

证据快照：`0ffa3c419fcc59dc3e13d695ca4658116134bfa0`。

`packages/rxdb-client-generator/src/generators/entity-properties.ts:67` 仅为非空 schema 声明精确接口；RxDBClientGenerator.utils.ts 的 getKeyValuePreciseType 对空 schema 返回 KeyValue，但属性生成器只登记 UUID 等导入，没有 KeyValue。`packages/rxdb-client-generator/src/generators/entity-rules.ts:90` 无论 schema 是否为空都使用 Partial<getFlatMapInterfaceName(...)>。真实 EmptyConfig.data 产物 referencesKeyValue=true、referencesPrecise=true、declaresPrecise=false、importsKeyValue=false。

## 修复方向

统一空 schema 的属性/规则类型策略，登记需要的通用类型导入或生成可用的空精确接口；补空 schema 完整客户端声明的消费方检查。
