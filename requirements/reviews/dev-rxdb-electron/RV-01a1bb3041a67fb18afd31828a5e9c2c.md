# RV-01a1bb3041a67fb18afd31828a5e9c2c：首页离开后未解除分支监听，重复导航累积旧组件与查询

## 问题与影响

在首页与 storage 或 todo 路由之间往返，每次创建 HomePage 都向应用级 RxDB 注册新的分支切换监听。组件离开路由后没有销毁钩子解除该监听，旧组件被 RxDB 一直持有；之后每次切换分支都会对所有历史组件重复执行 getCurrentBranch 并更新已离开的页面信号。长时间使用会累积组件和查询，定为 P2。

## 证据与根因

证据快照：`0ffa3c419fcc59dc3e13d695ca4658116134bfa0`。

`apps/dev-rxdb-electron/src/app/pages/home/home.page.ts:92` 使用捕获 this 的匿名函数 addEventListener(SWITCH_BRANCH_COMMIT, ...)；完整类只有 ngOnInit，没有 ngOnDestroy / DestroyRef / AbortSignal，也没有保存回调供 removeEventListener。`apps/dev-rxdb-electron/src/app/app.routes.ts:11` 与 :15 的首页和 storage 是不同的懒加载路由组件，RxDB 实例则由根 provider 持有。

轻量 Node 诊断以内存转译加载原始 HomePage，注入 EventTarget 形状的数据库与最小 Angular 装饰器/信号替身，创建并初始化两个代表两次路由进入的页面实例。单次 SWITCH_BRANCH_COMMIT 使 getCurrentBranch 调用增加 2 次，旧实例无销毁钩子可调用。替身未验证 Angular 渲染或真实数据库，只验证实际类注册的监听与生命周期缺口。

## 修复方向

用 DestroyRef.onDestroy 或 ngOnDestroy 解除该组件注册的监听，保存稳定回调或使用随组件销毁取消的订阅；增加两次进入首页、离开一次后只有当前组件响应分支事件的回归。
