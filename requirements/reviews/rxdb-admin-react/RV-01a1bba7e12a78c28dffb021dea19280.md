# RV-01a1bba7e12a78c28dffb021dea19280：命令面板把输入法确认回车当作执行命令

## 问题与影响

中日韩输入法正在组合文字，用户按 Enter 确认候选时，命令面板没有检查 composition 状态，立即执行当前选中项、关闭面板并可能导航或运行命令。误触发需要 IME 确认与结果列表交叠，记 P2。

## 证据与根因

证据快照：`0ffa3c419fcc59dc3e13d695ca4658116134bfa0`。

`packages/rxdb-admin-react/src/palette/command-palette.tsx:27` 仅按 event.key 判 Enter，未检查 event.nativeEvent.isComposing；Angular `packages/rxdb-admin-angular/src/palette/command-palette.component.ts:60`、Vue `packages/rxdb-admin-vue/src/palette/command-palette.vue:36` 的 DOM KeyboardEvent 同样没有 isComposing 保护。使用真实 React Provider+CommandPalette，打开面板后向输入框派发 key=Enter/isComposing=true，结果 navigated=[/A]、open=false、defaultPrevented=true。与普通 Enter 执行测试的预期不同，现有三端 palette-lock 测试均未覆盖组合输入。

## 修复方向

三端在处理 Enter/方向键前忽略输入法组合事件，React 读取 nativeEvent 对应字段；补组合确认不执行、compositionend 后普通 Enter 执行的回归。
