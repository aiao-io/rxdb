# 候选领域：智能体记忆 / 本地 AI 助手

> 本文是候选领域分析，不是用户故事，不参与状态统计。状态与维护规则见
> [本目录 README](README.md)。

**一句话结论**：「数据库即前端」形态的旗舰应用——智能体的长时记忆、运行日志、检索全落在
本地 SQLite，仓库的 sqliteai（向量列 + AI SQL 函数）、FTS5、会话录制回放正好拼出
「本地优先智能体」的数据层；引擎缺口在混合检索编排与本地 embedding（vision 阶段 6 方向
未交付），推理本身永远在引擎外（BYOK 或本地模型）。

**对标产品**：ChatGPT 记忆功能 / Claude Projects（品类）；Mem0 / Letta / Zep（记忆即产品的
独立赛道）；PrivateGPT / Open WebUI + Ollama（本地 AI 应用标杆）。

## 引擎缺口

- **混合检索编排**：FTS 与向量检索的统一编排是 vision 阶段 6 的方向、未交付——
  两个原语已交付，应用层组合可用
- **加密字段检索**：同字段「加密 + 可搜索」互斥（引擎会拒绝），加密记忆的全文 / 向量检索需应用层方案
- **本地 embedding 生成**：也是阶段 6 方向——可用外部 embedding API 绕开

## 引擎外成本

- **推理**：LLM API（BYOK——用户自己的 key 存本地加密库，保持零后端）或本地模型
  （Ollama / WebLLM，浏览器内跑大模型仍然重）
- **工具执行沙箱**：agent 的工具调用、文件读写是应用层职责
- **评测体系**：prompt / agent eval 是本赛道真正的长期成本，与引擎无关

## 架构要点

### Web / 本地对称

「一套支持 Web 和本地的智能体架构」成立，且是适配器无关哲学的字面兑现：同一套记忆 schema
在浏览器（OPFS）与桌面（Electron / Tauri 原生 SQLite）之间是同一份代码。分层：

- 数据层：rxdb（记忆 / 会话日志 / 任务状态实体 + 加密 + 备份）
- 检索层：FTS + sqliteai（原语已交付），混合编排应用层组合
- Agent 运行时：应用层（prompt loop、工具调用、模型路由）
- 推理：BYOK（Web 端现实路径）或本地模型（桌面端 + Ollama 现实路径，浏览器内 WebLLM 仍重）
- 同步（可选）：多设备记忆同步走 Supabase / HTTP；单机保持零后端

不对称点在**文件层**：Web 端只有 OPFS 虚拟文件系统，桌面端是真实文件系统——
虚拟环境能力天然是桌面端更强的（见下）。

### 虚拟环境：有价值，但分层要清晰

给智能体提供虚拟环境（git worktree / 文件系统隔离）的**真实价值场景**：

- agent 写代码 / 改文件需要隔离工作区，做错丢弃、做好合并——git worktree 是标准做法
- agent 多方案尝试（A/B 分支各试一遍）、回滚、比较——[working-tree 插件](../../packages/rxdb-plugin-working-tree)
  的分支 / 切换 / 冲突检测已交付（epic-006），正是「数据层虚拟环境」的内核
- agent 的实验性写入不污染主库——分支隔离的数据库状态

**边界（不做的部分）**：进程 / 文件系统级沙箱（防 agent 误删用户文件）需要 OS 层隔离
（容器 / VM），对标 E2B / Devbox / Daytona——不是引擎的题，也不是本候选的题。
rxdb 能提供的是「数据与分支的虚拟化」，不是进程沙箱。

**立项形态**：虚拟环境**不单独立项**——独立做就是重造 E2B，复杂度爆炸（ENFP 陷阱）。
作为智能体候选的子能力设计：立项时把 working-tree 包装成「agent 沙箱」API
（会话分支、隔离写入、回滚、合并），价值待证判据是写出「agent 改坏数据无法回滚」的具体症状。

Web 侧沙箱备选：WebContainers（StackBlitz 专有技术，浏览器内 Node 运行时 + 虚拟文件系统）——
可作演示 / 教程 / agent 沙箱的可选项，**不作为核心依赖**：专有技术与开源哲学冲突，
且对终端用户零价值（OPFS 已解决存储，WebContainers 解决的是 Node 进程）。

## 立项前置

无硬前置（检索原语应用层组合；embedding 与推理用外部 API）。

## 入场条件（什么信号才值得立项）

- 出现具名用户「和 AI 对话要反复交代背景 / 换设备记忆丢失」的具体症状
- 或作为 vision 阶段 6（搜索与本地 AI）的演示载体立项——记忆检索是混合检索最直观的展示
