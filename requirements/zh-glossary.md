# 中文注释词汇约定（zh-glossary）

> 配套 `AGENTS.md` 「`packages` 下 JS/TS 文件中的注释使用中文」。
> 本文是**项目内**的词汇规约：哪些词该用、哪些词要换、哪些词保留。
> 新人第一次改 packages 中文注释前先看；reviewer 在看注释 diff 时按本文档对线。

---

## 通用原则

1. **优先用领域标准译** — `claim` = 抢占、`host` = 宿主、`live query` = 活查询、`watermark` = 水位线
2. **避免北方口语** — 趟、顶账、钉住、回呼、惊动、他 tab
3. **避免文学化** — 惊动、起死、落地（除非确指 Promise settle）
4. **首次出现处加一行解释** — 纪元、宿主、claim、水位线
5. **英文 ID 已有标准词时，注释必须对齐** — `MIGRATION_CLAIM_RETRIES` 的 `claim` 应当译为「抢占」而不是「占坑」

## 三档对照

### 🔴 必改

| 原文                     | 改成                          | 理由 / 出处                                                                               |
| ------------------------ | ----------------------------- | ----------------------------------------------------------------------------------------- |
| 占坑 / 抢不到 / 占坑冲突 | 抢占 / 抢占失败 / 抢占冲突    | claim 标准译；`MIGRATION_CLAIM_RETRIES`、`RxDBMigrationClaimConflictError` 英文 ID 已对齐 |
| 顶账                     | 凑数 / 顶上                   | 北方口语；"拿别人的队列顶账" 改"凑数顶上"                                                 |
| 回呼                     | 回调                          | callback 旧译，现代不用，疑似笔误                                                         |
| 惊动                     | 唤醒 / 通知                   | RxJS Subject 上下文，文学化                                                               |
| 单趟                     | 单次 / 一次                   | 北方口语                                                                                  |
| 他 tab                   | 其他 tab                      | 注释中"他 tab 的变更"口语化                                                               |
| 钉住 / 钉死 / 钉在一起   | 锁死 / 固定 / 绑在一起        | 北方口语                                                                                  |
| 吃掉了                   | 替换了 / 抹掉了               | `rxdb-devtools/serializer.ts` "吃掉了要调试的数据" 口语贴但非术语                         |
| 占着                     | 占用                          | `rxdb-plugin-workspace` 注释                                                              |
| 挂在 rxdb 上             | 由 rxdb 引用 / 挂到 rxdb 实例 | `rxdb-plugin-graph` 注释口语                                                              |
| 清了再连                 | 清理后重连                    | `rxdb-test` 注释                                                                          |

### 🟡 可改可不改

| 原文             | 候选          | 备注                                                 |
| ---------------- | ------------- | ---------------------------------------------------- |
| 撑爆             | 超出 / 撑满   | `rxdb-adapter-supabase` / `rxdb-adapter-sqlite-core` |
| 落地             | settle / 完成 | 确指 Promise 落地时改 `settle` 更专业                |
| 死对象           | 已释放对象    | 准确但生造，"死对象" 在 Rust/FFI 圈共识              |
| 死实例           | 已失败实例    | 同上                                                 |
| 死胡同           | 死循环 / 死锁 | 准确但语感偏文学                                     |
| 拦 / 拦下 / 拦腰 | 拦截 / 截断   | 单字清晰但正式度低                                   |
| 走完 / 走到      | 完成 / 落到   | 标准动词                                             |
| 入 / 进          | 入栈 / 入队   | 加宾语更明确                                         |

### 🟢 保留（项目内已统一 / 领域共识）

| 词          | 出处                 | 理由                                     |
| ----------- | -------------------- | ---------------------------------------- |
| 纪元        | rxdb / utils         | DB / Raft / EBR 共识；项目内 6+ 文件统一 |
| 宿主        | 10+ 项目             | 学术 / 分布式标准词（host）              |
| 活查询      | rxdb / rxdb-test     | 项目内既有术语（live query）             |
| 水位线      | rxdb / supabase      | DB / 事件流标准（watermark）             |
| 就绪门      | sqlite-core          | `ready()` 闸门隐喻，行业常见             |
| 半成品      | 6+ 项目              | 准确、简洁                               |
| 半拆 / 半装 | rxdb                 | 准确、简洁                               |
| 放行        | 6+ 项目              | 含义清晰                                 |
| 退回去      | rxdb                 | 逆序拆卸的"退"字很贴                     |
| 裸          | electron             | 准确（raw BEGIN）                        |
| 桩          | client-generator     | 标准（stub）                             |
| 钩子        | 5+ 项目              | 标准（hook）                             |
| 管道 / 管子 | electron / encrypted | 准确（pipe）                             |
| 切片        | sqlite-script        | 标准（slice）                            |
| 拦 / 拦下   | 5+ 项目              | 准确                                     |
| 落 / 落到   | 多项目               | 准确                                     |

| 报成 / 报到 | rxdb                 | "报成断开" 准确                          |
| 闸          | sqlite-core          | 准确（gate）                             |

## 按项目分组的"项目特有词"

### `packages/rxdb`（核心）

- 高频：**占坑**、**顶账**、**回呼**、**惊动**、**单趟**、**他 tab**、活查询、死对象、**纪元**、水位线
- 🔴 占坑系列、顶账、回呼、惊动、单趟、他 tab 全改
- 🟢 纪元、活查询、水位线、半成品、半拆、放行 保留

### `packages/utils`

- 词：连接纪元、`connection-epoch`、scope 过期
- 🟢 全部保留；`lifecycle-scope.interface.ts` 的「重新取得当前纪元的作用域」已是项目内标准译

### `packages/rxdb-adapter-sqlite-core`

- 词：就绪门（`ready()` gate）、放行、半成品、撑满、撑爆、裸
- 🟢 就绪门、放行、半成品、裸 保留
- 🟡 撑满 / 撑爆 改「撑满 / 超出」

### `packages/rxdb-adapter-electron`

- 词：半成品桥接、管子、桥、宿主、**钉住**
- 🔴 钉住 改"锁死"
- 🟢 半成品、管子、桥、宿主 保留

### `packages/rxdb-adapter-supabase`

- 词：水位线（`sinceId`）、**撑爆**、活查询
- 🟢 水位线、活查询 保留
- 🟡 撑爆 改"超出"

### `packages/rxdb-adapter-tauri`

- 词：Rust 宿主、传输层、`node:sqlite` 宿主
- 🟢 全部保留（标准术语）

### `packages/rxdb-adapter-pglite`

- 词：宿主、拦腰截断、影子表
- 🟢 全部保留

### `packages/rxdb-angular` / `react` / `vue`

- 词：宿主（统一）、挂入管道、占位值、`shallowRef`、`markRaw`、销毁钩子
- 🟢 全部保留（标准前端术语）

### `packages/rxdb-plugin-search`

- 词：**钉在一起**、短路、漂移检测放行
- 🔴 钉在一起 改"绑在一起"
- 🟢 短路、放行 保留

### `packages/rxdb-plugin-storage`

- 词：宿主、三处宿主改动
- 🟢 全部保留

### `packages/rxdb-plugin-workspace`

- 词：其他 tab、**占着**旧版本
- 🔴 占着 改"占用"
- 🟢 跨 tab、阻塞 保留

### `packages/rxdb-plugin-graph`

- 词：已拆掉的纪元、**挂在 rxdb 上**
- 🔴 挂在 rxdb 上 改"由 rxdb 引用"
- 🟢 纪元 保留

### `packages/rxdb-client-generator`

- 词：桩（stub）、半成品、死循环、孤儿节点
- 🟢 全部保留

### `packages/rxdb-devtools`

- 词：**吃掉了**要调试的数据
- 🔴 吃掉了 改"替换了"
- 🟢 缓冲区、附着、快照 保留

### `packages/rxdb-test`

- 词：活查询、**清了再连**
- 🔴 清了再连 改"清理后重连"
- 🟢 活查询 保留

### `packages/code-editor*`

- 词：宿主、`Compartment`、facet
- 🟢 全部保留（CodeMirror 既有术语）

## 维护规则

- 改一份注释前先 `rg` 该词在仓库的出现位置，确认没有冲突含义
- 新增注释若引入新词（领域术语、外来语、口语）必须先在本文档登记评级
- 旧注释改动时顺手按本文档对线，单点改动即可，不必一次扫全仓
