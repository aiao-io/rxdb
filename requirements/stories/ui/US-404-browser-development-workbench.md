# 用户故事：浏览器本地开发工作台

## 作为/我想要/以便

**作为** 已在浏览器里编辑前端代码的开发者
**我想要** 在同一个工作台中管理项目文件、保存与提交、运行预览，并完整导出项目
**以便** 不切换本地开发环境就能验证修改，关闭页面后继续工作，也能带着源码和 Git 历史退出

具体症状：现有编辑器只编辑文本，Git 研究 Demo 与它分离；编辑后不能在同一入口运行项目，
也没有经验证的项目导出与恢复路径。可行性依据和官方实现对照见
[研究附件](US-404-online-development-feasibility.md)。

## 范围边界

### In Scope

- 单人 Web 开发工作台；首版支持已验收的 Chromium 桌面浏览器与安全上下文，缺少能力时明确拒绝。
- HTML / CSS / JS / TS、React TSX、Vue SFC、Angular standalone 四类受控模板，固定依赖版本。
- 文件树、多文件编辑、显式保存、运行与重新运行、console / 错误定位；预览更新允许整页重载。
- 使用 Dockview 管理布局，使用微软官方 Codicons，模拟 VS Code 的工作台布局与常用交互：活动栏、文件 / Git 侧栏、多标签编辑区、右侧预览、底部面板和状态栏。
- 独立 OPFS 项目与真实 Git 的 init、status、add、commit、log；把指定可达提交的文件树恢复成工作区差异，HEAD 与 index 不变。
- 完整项目归档导入导出，包含 `.git`；标准工具链可独立构建运行的框架模板。
- 复用 US-402 编辑器，Angular / React / Vue 三端宿主提供相同能力与共享核心 API。
  宿主框架与所编辑项目的框架独立，不能只在同名宿主运行对应模板。

### Out of Scope

- 任意 npm / Nx 仓库、浏览器内 `pnpm install`、安装脚本、Node API、终端、SSR、原生扩展。
- Angular CLI / AOT 完整兼容、任意 Vite / Webpack 插件、CSS 预处理器与任意 npm 依赖安装。
- 远端 Git clone / fetch / push、私库认证、合并 / rebase、多工作树、实时协作、AI agent 与部署发布。
- 完整语言服务器、完整 TS 类型检查与断点调试；不把语法高亮或转译成功称为类型检查通过。
- Electron / Tauri、移动浏览器、其他浏览器兼容矩阵，以及跨设备同步文件。
- 使用宿主 RxDB / OPFS 作为预览应用的数据源；预览应用需要持久数据时另行验收其独立 origin 与数据隔离。

## 技术笔记

- 三端共用 `dockview-core` 的原生面板、左侧 edge group、标签拖拽和分割尺寸；编辑器与预览使用 `renderer: always` 保留 DOM。图标、样式和字体使用自托管官方 Codicons 资源，许可证随包分发。

- 依赖已交付的 [US-402](US-402-code-editor.md)。Git 原型需按
  [现有研究](../../domain-research/browser-git-opfs.md)补齐产品契约，不能把数据库 working-tree 当真实 Git。
- Git Worker 独占项目文件，编辑器通过命令保存；编译 Worker 只消费带 `projectId / revision` 的不可变快照。
  编译输出与依赖缓存不写回工作树；RxDB 保存项目目录与会话设置，不虚构跨 OPFS / DB 的原子事务。
- 推荐受控编译路线，具体转译器和模块实现由 A 的证据确定。Angular JIT 已由固定模板和普通 AOT 导出分别验证；
  不能把其运行时模板编译全部宣称发生在后台 Worker，也不能用单纯 TS 转译代替 Angular 语义处理。
- 预览使用 opaque origin 与 credentialless iframe，和 IDE 的存储 / 凭据隔离。此边界不宣称阻断任意 JavaScript 的导航或 WebRTC 网络访问。若 sandbox 开启 `allow-same-origin`，
  它指向独立预览 origin；不允许把 IDE 同源 `srcdoc` 配上 `allow-scripts + allow-same-origin`。
  项目之间采用 opaque origin 或经实测的逐项目 origin 隔离；不能让同一预览 origin 的存储遗留供下一项目读取。
- 依赖与编译器资源自托管或镜像到可控站点，按模板锁定版本与摘要。安装发生在模板制作 / 导出验证时，
  不在浏览器工作区执行包脚本。体积、资源上限和性能预算由 A 的真实 fixture 测量后固化。
