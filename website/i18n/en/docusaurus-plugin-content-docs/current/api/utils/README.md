# utils

Aiao project general utility library, providing common utility functions.

## Features

- **Type utilities**: TypeScript type enhancements
- **String utilities**: common string operations
- **Time utilities**: date/time helpers
- **RxJS utilities**: RxJS helper functions

## Installation

```bash
npm install @aiao/utils
# or
pnpm add @aiao/utils
```

## Usage

```typescript
// UTL-031: deepClone / formatTime from the earlier examples do not exist in this package; copying them verbatim fails to compile
import { cloneDeep, debounce, formatPassTime } from '@aiao/utils';

const copy = cloneDeep({ nested: { value: 1 } });
const onInput = debounce((text: string) => console.log(text), 300);
const elapsed = formatPassTime(startedAt, new Date());
```
