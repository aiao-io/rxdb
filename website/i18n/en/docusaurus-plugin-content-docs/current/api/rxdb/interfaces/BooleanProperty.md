# BooleanProperty

Defined in: [packages/rxdb/src/entity/property-types.interface.ts:380](https://github.com/aiao-io/rxdb/blob/b5232040240cf1ccfbab0ebf9ba882a4af8268a0/packages/rxdb/src/entity/property-types.interface.ts#L380)

Boolean property.

## Remarks

The SQLite family has no native boolean type; it lands in a `0` / `1` integer column and is restored on read,
so raw SQL queries (`rawQuery`) must compare by integer and must not write `= true`.
