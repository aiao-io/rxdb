# BigIntProperty

Defined in: [packages/rxdb/src/entity/property-types.interface.ts:332](https://github.com/aiao-io/rxdb/blob/b5232040240cf1ccfbab0ebf9ba882a4af8268a0/packages/rxdb/src/entity/property-types.interface.ts#L332)

Signed 64-bit integer property.

## Remarks

At runtime only accepts `bigint`, with a value range of `-2^63` to `2^63 - 1`. The SQLite family and
PGlite local adapters support persistence; Supabase remote does not.

- `IEntityObject`
- `ISortable`
