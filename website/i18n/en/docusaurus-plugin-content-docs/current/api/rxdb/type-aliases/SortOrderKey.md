Manual ordering key

## Remarks

A fractional index key generated by `@aiao/utils`'s default alphabet, compared in codepoint lexicographic order (case-sensitive).
A plain `string` alias rather than a branded type: tree entities combine it into `SortOrderKey | null`,
and a branded type would break all existing string assignments.
