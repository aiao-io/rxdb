# I18n

Defined in: [i18n.ts:64](https://github.com/aiao-io/rxdb/blob/b5232040240cf1ccfbab0ebf9ba882a4af8268a0/packages/rxdb-i18n/src/i18n.ts#L64)

Internationalization runtime backed by RxDB language preferences and catalogs.

## Remarks

Usable immediately after construction in static mode; in persistence mode, await init() before rendering the first screen. Same-origin cross-tab notification is handled by RxDBTabsGateway; multiInstance:false does not receive writes from other instances.
