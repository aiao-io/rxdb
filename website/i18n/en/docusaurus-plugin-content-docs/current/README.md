# Documentation map

RxDB gives Angular, React, and Vue applications an in-browser database, reactive queries, and a shared entity model. Start with the local read/write path, then add UI bindings, internationalization, collaboration, or synchronization as needed.

- [Getting Started](/getting-started/README.md) covers the smallest model, database, read/write, and UI path.
- [Capabilities and examples](/getting-started/capabilities.md) lists the runnable applications and current boundaries.
- [Model definition](/model-definition/README.md), [queries](/model-query/README.md), and [mutations](/model-mutation/README.md) cover the core data API.
- [Framework integration](/frameworks/README.md) covers Angular Signals, React Hooks, and Vue Composables.
- [Entity model](/entity-model/README.md) covers metadata-driven UI and headless state.
- [Admin shell](/admin-shell/README.md) covers navigation, layout, themes, and the three framework templates.
- [Client internationalization](/i18n/README.md) covers ICU messages, formatting, catalogs, and language preferences.
- [Adapters](/adapters/README.md) explains browser, desktop, HTTP, Supabase, and mini-program storage options.
- [Plugins](/plugins/README.md) covers history, sync, search, boards, and P2P file sharing.
- [API reference](/api/README.md) links to package examples, exported types, and core error codes.
- [Compatibility](/compatibility.md) records runtime, framework, and package constraints.

The Admin, I18n, Board, and P2P package families are currently workspace packages. Run the examples from this repository until those packages are published.

To run the checks or open a pull request, follow the [contributing guide](https://github.com/aiao-io/rxdb/blob/main/CONTRIBUTING.md).
