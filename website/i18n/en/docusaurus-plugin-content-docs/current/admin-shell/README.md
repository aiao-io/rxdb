# Admin shell

`@aiao/rxdb-admin` provides shared navigation, layout, theme, preference, and internationalization primitives for the Angular, React, and Vue Admin templates.

The templates share the same language preference behavior. An explicit saved choice wins over the host language, clearing the choice restores host-language detection, and the current locale updates page metadata and visible formatting.

See [Admin preferences](/admin-shell/preferences.md), [framework templates](/admin-shell/frameworks.md), and the runnable applications for the complete integration.
