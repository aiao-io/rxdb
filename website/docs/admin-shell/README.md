# 后台外壳（rxdb-admin）

`@aiao/rxdb-admin` 系列是**后台管理的外壳层**：布局（侧栏 / 顶栏 / 页签栏 / 页脚）、偏好抽屉、主题、快捷键、命令面板、锁屏、水印、时区与语言切换，一次实现，Angular / React / Vue 三端 DOM 契约一致。它和 [实体模型（rxdb-model）](../entity-model/README.md) 配合：外壳管"壳"，模型管"页面里的实体列表 / 详情 / 表单"。

核心库零框架依赖，与路由库无关——应用只负责把当前地址告诉外壳、在 `navigate` 回调里跳转。三端壳只做渲染。

## 包结构

| 包                         | 说明                                                                                                     |
| -------------------------- | -------------------------------------------------------------------------------------------------------- |
| `@aiao/rxdb-admin`         | 框架无关核心：偏好 schema 与存储、主题、布局推导、页签、快捷键、命令面板、锁屏、水印、时区、外壳文案目录 |
| `@aiao/rxdb-admin-angular` | Angular 壳：`AdminLayoutComponent`、偏好抽屉、命令面板、锁屏等独立组件                                   |
| `@aiao/rxdb-admin-react`   | React 壳：`AdminLayout`、`AdminShellProvider` 与 hooks                                                   |
| `@aiao/rxdb-admin-vue`     | Vue 3 壳：`AdminLayout`、`AdminShellProvider` 与 composables                                             |

## 接入状态

当前包族尚未进入 npm 发布集合，先从仓库工作区验证。包名与代码示例描述当前 main 的接入方式，不能把工作区的 `0.0.28` 当作这些包已经发布的证明。本地运行入口见[能力与示例](../getting-started/capabilities.md)。

外壳的样式由应用的 Tailwind + daisyUI 管线生成，包不发布编译样式：在样式入口引入绑定包的 `tailwind.css`（让 Tailwind 扫描组件里用到的类）和核心包的 `admin.css`（三端共享的样式契约）。接入步骤见[三端用法](./frameworks.md)。

## 你会得到什么

| 分组             | 能力                                                                                                                           |
| ---------------- | ------------------------------------------------------------------------------------------------------------------------------ |
| 外观             | 35 个 daisyUI 主题（应用挑选子集、跟随系统）、主色、圆角、字号、半深色侧栏 / 顶栏、紧凑密度、灰色 / 色弱模式                   |
| 布局与页签       | 四种布局模式、侧栏图标轨 / 悬停展开 / 拖拽调宽、移动端抽屉、面包屑、页脚、内容区宽度；多页签（固定、拖拽排序、右键菜单、历史） |
| 快捷键与命令面板 | `Mod+K` 命令面板（页面 / 命令 / 最近使用 / 应用自有来源）、`Mod+,` 偏好、`Alt+L` 锁屏、`Mod+B` 折叠侧栏、`Alt+W` 关闭页签      |
| 顶栏部件与通用   | 语言、时区、主题、全屏、刷新、锁屏；页面切换动画、动态标题、水印、版权页脚、Logo                                               |
| 扩展             | 应用自己的设置项注册为扩展，出现在偏好抽屉的「拓展」页签                                                                       |

全部设置存放在本机，只保存**相对默认值的差异**，同源多标签自动同步，刷新后首帧就是上次的主题，不闪烁。细节见[偏好、主题与扩展](./preferences.md)。

## 设计取舍

- **声明式 schema**：偏好抽屉按 schema 通用渲染，没有手写表单；增加一个设置项只需要声明它。
- **外壳是壳**：不接管路由、不接管数据。菜单是一棵 `MenuNode` 树，页面内容是 `children` / 默认插槽。
- **三端同一份契约**：DOM 结构、CSS 类名、`aria-*` 与 `data-testid` 三端一致，同一套端到端用例可以对三端复用。
- **锁屏是"防偷看"**：不是访问控制，也不加密数据，详见[偏好、主题与扩展](./preferences.md#锁屏的边界)。

## 参考实现

仓库里的 `apps/rxdb-admin-template-{angular,react,vue}` 提供三端完整接入（菜单、实体计数徽标、命令面板里的全文搜索来源、"每页条数"扩展、旧存储键迁移）。开发端口分别为 4207、4206、4208；各模板的 `-e2e` 项目复用 `apps/rxdb-admin-template-react-e2e/src` 中的端到端与无障碍场景，验证各自的生产构建。
