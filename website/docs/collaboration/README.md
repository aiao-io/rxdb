# 数据协作

协作能力建立在本地链路稳定之后。这里讲的是版本、同步与可恢复性,不是实时协作文档系统。

**状态**:MVP 已验证——分支、撤销重做、条件同步、跨 Tab 同步都可直接运行。

## 能力范围

| 能力                       | 用途                               |
| -------------------------- | ---------------------------------- |
| [分支](./branch.md)        | 隔离变更、组织工作流、处理并行编辑 |
| [同步](./sync.md)          | 本地与远端之间的数据交换方式       |
| [撤销重做](./undo-redo.md) | 让用户操作具备可逆性与可恢复性     |

## 当前不包含

- 细粒度权限系统
- 托管云服务

## 什么时候读这一章

- 已经理解实体模型与基础查询
- 应用开始出现离线编辑、多端协同、冲突处理需求
- 不想让协作逻辑散落在 UI 层和接口调用里
