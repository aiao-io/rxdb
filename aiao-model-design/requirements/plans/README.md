# 计划与验收记录

调研结论、实施计划、真实环境验收记录和历史归档。当前范围与状态以[需求索引](../README.md)、`status-overview.md`、`roadmap.md` 和各 story 为准；这里的记录带日期，不作为当前状态的派生视图。

| 类别     | 回答的问题                                   |
| -------- | -------------------------------------------- |
| 调研结论 | 借鉴对象怎么做、哪些适用、哪些不适用         |
| 实施计划 | 已确定的方案、实施切片与任务清单             |
| 验收记录 | 已经验证什么、还缺什么、证据来自哪一层       |
| 历史归档 | 范围调整前的路线图与验收记录，不作为当前证据 |

产品规则写在对应 story；计划记录研究结论、依赖与实施切片，不能代替实现证据。文件名用 `<主题>-research.md` 区分调研、`<主题>-tasks.md` 区分实施清单、`<主题>-verification.md` 区分验收记录，历史归档用 `<主题>-<日期>.md`。
