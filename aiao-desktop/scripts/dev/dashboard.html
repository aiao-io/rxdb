  • 终端依赖跨源隔离 状态显示「缺少 COOP / COEP」时 Vivari 无法启动；开发服务器与正式构建预览都应返回这两个响应头。
  • 外网内容可以缺失 壁纸、地图瓦片、天气与 Safari 阅读模式来自外网，拿不到时应用照常打开，页面不应报错。
  • 改可见行为要补冒烟 冒烟检查项与需求 ADESK-US-101 的验收标准一一对应，改动时两边一起改。
