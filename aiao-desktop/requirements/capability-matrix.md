# Aiao Desktop 能力矩阵

本表区分源码可见的现有能力与故事的验收状态。执行证据见 [verification-report](verification-report.md)。

| 能力                       | 当前入口与边界                                                                                                                                                                                                                                                                                                                                                                                            | 产品验收                                                                                                             |
| -------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------- |
| 开机、锁屏、睡眠与关机     | [session.ts](../apps/web/src/app/services/session.ts)、[boot-screen.ts](../apps/web/src/app/components/boot-screen.ts)、[lock-screen.ts](../apps/web/src/app/components/lock-screen.ts)；`?boot=0` 或 `#noboot` 跳过开机动画                                                                                                                                                                              | ADESK-US-101 只验证跳过开机后的桌面；开机、锁屏、睡眠流程未进冒烟                                                    |
| 菜单栏与菜单               | [menubar.ts](../apps/web/src/app/components/menubar.ts)、[status-panels.ts](../apps/web/src/app/components/menubar/status-panels.ts)、[control-centre.ts](../apps/web/src/app/components/menubar/control-centre.ts)：Apple 菜单、前台应用菜单、状态栏面板与控制中心                                                                                                                                       | ADESK-US-101 #4；状态栏面板与控制中心未验证                                                                          |
| Dock、窗口与最小化         | [dock.ts](../apps/web/src/app/components/dock.ts)、[dock-state.ts](../apps/web/src/app/services/dock-state.ts)、[window-manager.ts](../apps/web/src/app/services/window-manager.ts)、[window-frame.ts](../apps/web/src/app/components/window-frame.ts)                                                                                                                                                    | ADESK-US-101 #1、#5；拖动、缩放、全屏与多窗口排布未验证                                                              |
| 启动台、聚焦搜索与通知中心 | [launchpad.ts](../apps/web/src/app/components/overlays/launchpad.ts)、[spotlight.ts](../apps/web/src/app/components/overlays/spotlight.ts)、[notification-centre.ts](../apps/web/src/app/components/overlays/notification-centre.ts)、[widgets.ts](../apps/web/src/app/components/widgets/widgets.ts)                                                                                                     | ADESK-US-101 #7～#9                                                                                                  |
| Finder 与磁盘              | [file-system.ts](../apps/web/src/app/services/file-system.ts)、[rxdb-disk-store.ts](../apps/web/src/app/disk/rxdb-disk-store.ts)、[finder.ts](../apps/web/src/app/apps/finder/finder.ts)：目录树是本地 SQLite 里的 `DesktopFile` 行，文件体由 storage 插件放在 OPFS；桌面图标来自 `~/Desktop`；TextEdit 与预览读写真实文件；磁盘工具可抹掉恢复（[D-08](decisions.md#d-08文件体由-storage-插件放在-opfs)） | ADESK-US-101 #2；ADESK-US-102 #1～#4、#10、#11                                                                       |
| 终端                       | [terminal-tab.ts](../apps/web/src/app/apps/terminal/terminal-tab.ts)、[virtual-machine.ts](../apps/web/src/app/vm/virtual-machine.ts)：xterm 与 `@vivari/core`，需要跨源隔离（[D-05](decisions.md#d-05终端依赖跨源隔离)）；打开时把磁盘复制进共用的虚拟机，双向同步，补了 touch / mv / cp / open（[D-09](decisions.md#d-09终端按需复制磁盘)）                                                             | ADESK-US-101 #6；ADESK-US-102 #5～#9                                                                                 |
| 本地数据                   | [desktop-database.ts](../apps/web/src/app/data/desktop-database.ts)、[desktop-data.ts](../apps/web/src/app/data/desktop-data.ts)、[system-settings.ts](../apps/web/src/app/services/system-settings.ts)：`@aiao/rxdb` + sqlite-wasm，系统设置、桌面图标位置、最近使用与各内置应用的数据都在库里（[D-07](decisions.md#d-07系统数据存在本地-sqlite)）                                                       | ADESK-US-102                                                                                                         |
| 内置应用                   | [registry.ts](../apps/web/src/app/apps/registry.ts)：启动台列出 29 个应用，App Store、Podcasts、TV 与 Books 共用书架组件；17 个应用的数据是本地库里的实体（`<app>.entities.ts`），首次打开写入初始数据                                                                                                                                                                                                    | ADESK-US-101 #10 只验证都能打开；ADESK-US-102 #12 验证备忘录与提醒事项的数据跨刷新保留，其余应用的内部功能未逐一验收 |
| 外网内容                   | 壁纸、地图瓦片、地名搜索、天气、Safari 阅读模式、网站图标与网页字体（[D-04](decisions.md#d-04外网内容可缺失)）                                                                                                                                                                                                                                                                                            | 未验收：冒烟拦截全部外网请求，只证明拿不到时页面不报错（ADESK-US-101 #11）                                           |
| 安全边界                   | [check-web-secrets.mjs](../scripts/check-web-secrets.mjs)：扫描 web 构建产物里的密钥形状（[D-03](decisions.md#d-03只有前端不带任何密钥)）                                                                                                                                                                                                                                                                 | ADESK-US-001 #6                                                                                                      |
| 本地开发入口与开发导航     | [services.mjs](../scripts/dev/services.mjs)、[dashboard.mjs](../scripts/dev/dashboard.mjs)：`pnpm nx dev aiao-desktop` 启动开发服务器（4410）与开发导航（4412），正式构建预览（4411）按需启动；端口固定（[D-06](decisions.md#d-06本地开发用固定端口与开发导航)）                                                                                                                                          | ADESK-US-002                                                                                                         |

不支持声明：窗口布局不跨刷新保留；多个标签页同时打开时，彼此的改动刷新后才看得到；只在桌面尺寸的 Chromium 上验证过，Safari、Firefox、触屏与移动端尺寸没有验收；没有正式部署目标。
