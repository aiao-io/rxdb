# Aiao Desktop 能力矩阵

本表区分源码可见的现有能力与故事的验收状态。执行证据见 [verification-report](verification-report.md)。

| 能力                       | 当前入口与边界                                                                                                                                                                                                                                                                                        | 产品验收                                                                   |
| -------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------- |
| 开机、锁屏、睡眠与关机     | [session.ts](../apps/web/src/app/services/session.ts)、[boot-screen.ts](../apps/web/src/app/components/boot-screen.ts)、[lock-screen.ts](../apps/web/src/app/components/lock-screen.ts)；`?boot=0` 或 `#noboot` 跳过开机动画                                                                          | ADESK-US-101 只验证跳过开机后的桌面；开机、锁屏、睡眠流程未进冒烟          |
| 菜单栏与菜单               | [menubar.ts](../apps/web/src/app/components/menubar.ts)、[status-panels.ts](../apps/web/src/app/components/menubar/status-panels.ts)、[control-centre.ts](../apps/web/src/app/components/menubar/control-centre.ts)：Apple 菜单、前台应用菜单、状态栏面板与控制中心                                   | ADESK-US-101 #4；状态栏面板与控制中心未验证                                |
| Dock、窗口与最小化         | [dock.ts](../apps/web/src/app/components/dock.ts)、[dock-state.ts](../apps/web/src/app/services/dock-state.ts)、[window-manager.ts](../apps/web/src/app/services/window-manager.ts)、[window-frame.ts](../apps/web/src/app/components/window-frame.ts)                                                | ADESK-US-101 #1、#5；拖动、缩放、全屏与多窗口排布未验证                    |
| 启动台、聚焦搜索与通知中心 | [launchpad.ts](../apps/web/src/app/components/overlays/launchpad.ts)、[spotlight.ts](../apps/web/src/app/components/overlays/spotlight.ts)、[notification-centre.ts](../apps/web/src/app/components/overlays/notification-centre.ts)、[widgets.ts](../apps/web/src/app/components/widgets/widgets.ts) | ADESK-US-101 #7～#9                                                        |
| Finder 与虚拟文件系统      | [file-system.ts](../apps/web/src/app/services/file-system.ts)、[finder.ts](../apps/web/src/app/apps/finder/finder.ts)：目录树写在代码里，只存在内存中                                                                                                                                                 | ADESK-US-101 #2；不持久化，刷新即复原                                      |
| 终端                       | [terminal-tab.ts](../apps/web/src/app/apps/terminal/terminal-tab.ts)：xterm 与 `@vivari/core`，需要跨源隔离（[D-05](decisions.md#d-05终端依赖跨源隔离)）                                                                                                                                              | ADESK-US-101 #6                                                            |
| 内置应用                   | [registry.ts](../apps/web/src/app/apps/registry.ts)：启动台列出 29 个应用，App Store、Podcasts、TV 与 Books 共用书架组件                                                                                                                                                                              | ADESK-US-101 #10 只验证都能打开；各应用的内部功能未逐一验收                |
| 外网内容                   | 壁纸、地图瓦片、地名搜索、天气、Safari 阅读模式、网站图标与网页字体（[D-04](decisions.md#d-04外网内容可缺失)）                                                                                                                                                                                        | 未验收：冒烟拦截全部外网请求，只证明拿不到时页面不报错（ADESK-US-101 #11） |
| 安全边界                   | [check-web-secrets.mjs](../scripts/check-web-secrets.mjs)：扫描 web 构建产物里的密钥形状（[D-03](decisions.md#d-03只有前端不带任何密钥)）                                                                                                                                                             | ADESK-US-001 #6                                                            |

不支持声明：不保存任何状态，刷新即复原；只在桌面尺寸的 Chromium 上验证过，Safari、Firefox、触屏与移动端尺寸没有验收；没有正式部署目标。
