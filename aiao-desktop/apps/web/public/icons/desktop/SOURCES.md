# 桌面图标来源

- 应用 PNG 来自本地 `macOS-26-Icons`，保留透明边距，缩放到 256 × 256。启动台使用 `Apps.png`，几猫3A大作使用 `Games.png`。
- `app-github.png` 来自本机 GitHub Desktop 的 `electron.icns`，保留系统图标的透明边距。
- `app-trash.png` 和 `app-trash-full.png` 来自本机 macOS 15.7.9 的 `Dock.app`，分别对应 `trashempty@2x.png` 和 `trashfull@2x.png`。
- `f-*.png` 来自本机 macOS 15.7.9 Finder 使用的系统文件类型图标。`g-apple.svg` 来自本机 Helvetica 字体中的 Apple 标志。
- `app-aiao-code.png` 是从本机 `/Applications/Visual Studio Code.app/Contents/Resources/Code.icns` 提取的 256 × 256 原生图层，保留透明边距。
- 其余 `g-*.svg` 来自 Lucide 1.70.0；`g-trash.svg` 是 Lucide 1.77.0（随 `@lucide/angular` 安装）的 `trash`。许可见 [LUCIDE-LICENSE.txt](LUCIDE-LICENSE.txt)。
