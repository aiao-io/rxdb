开发提示

  • 端口固定，不换号 被占用时直接报错，不会顺延到别的端口。在终端里（TUI）强行结束 nx 不留进程；用 --tui=false 跑时被强杀，React / Vue 的 vite 可能残留，结束占用 4206 / 4208 的进程即可。
  • 哪些改动会热更新 三端代码与协作包的浏览器端代码改完即生效；协作包服务端代码 src/server 改了要重启 nx dev。
  • 验证码与会话 验证码 1 小时内有效、只能用一次；access token 15 分钟，页面在到期前自动刷新。收不到验证码先看 Auth 日志。
  • 数据在哪里 匿名工作台在浏览器的 sqlite-wasm + IndexedDB，清站点数据即重置；团队数据在 PostgreSQL，清空用「清空数据重来」。
  • 改了数据模式 实体定义变了要重新生成 schema/collaboration-schema.json 并提高版本，已有团队经「数据模式」命令登记新版本。
  • 与发布预演共用 deploy-local 把三端产物发布到 4510～4512；做迁移验收前先清空数据，从干净的栈开始。
